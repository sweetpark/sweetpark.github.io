📘 정보보안 기초 용어 정리 (교재 요약)

1. 정보보안 기본 개념

🔐 보안 3요소 (CIA Triad)

요소의미
기밀성 (Confidentiality)허가되지 않은 접근으로부터 정보 보호
무결성 (Integrity)데이터의 정확성과 완전성 유지
가용성 (Availability)필요 시 자산을 정상적으로 이용 가능

2. 주요 공격 기법

네트워크 기반 공격

  • 스니핑 (Sniffing)

    → 네트워크 트래픽을 도청·감청하는 공격

  • 스푸핑 (Spoofing)

    → 신뢰 가능한 대상으로 위장

    • 예: ARP Spoofing
    • 일반적으로 변조(Tampering) 이후 악용

3. 데이터 & 데이터 보안

  • 데이터베이스(Database)

    → 구조화된 데이터 저장소

  • 데이터 보안(Data Security)

    → 데이터의 기밀성·무결성·가용성 보호

  • 데이터베이스 보안(DB Security)

    → DB 접근 통제, 계정 관리, SQL 보안 등

4. 네트워크 관련 용어

  • 네트워크 노드(Node)

    → 컴퓨터, 프린터, 네트워크 장비 등 연결 지점

  • 네트워크 시스템

    → 노드 + 통신 장비 + 프로토콜의 집합

  • 로드 밸런싱(Load Balancing)

    → 트래픽을 여러 서버로 분산 처리

5. 악성 행위 및 위협 용어

용어설명
백도어공격자가 원격 접근을 위해 숨겨둔 통로
취약점(Vulnerability)시스템의 보안 약점
멀웨어(Malware)악의적 행위를 수행하는 프로그램
크랙(Crack)소프트웨어 보호 기능 무력화
제로데이(Zero-day)패치가 존재하지 않는 취약점 공격
익스플로잇(Exploit)취약점을 이용해 의도된 동작 수행

6. 보안 관리 및 정책 용어

보안 관리 영역

  • 관리적 보안 : 정책, 규정, 교육
  • 기술적 보안 : 방화벽, IDS/IPS, 암호화
  • 물리적 보안 : 출입통제, CCTV

주요 개념

  • 접근 권한 / 접근 통제

  • 보안 정책(Security Policy)

  • 보안 평가(Security Assessment)

  • 정보보호 감사

  • 부인방지(Non-repudiation)

    → 행위 발생 사실을 증명하여 부인 불가

보안 시스템

시스템역할
IDS침입 탐지
IPS침입 차단
터널링특정 사용자만 사용하는 통신 경로
백업센터재해 복구용 별도 시스템

7. 인프라(Infrastructure)

  • 인프라

    → HW + SW + OS + 네트워크 + 미들웨어

운영 환경

구분설명
On-Premises자체 전산실에 직접 구축
Cloud외부 클라우드 환경 활용

클라우드 서비스 모델

모델특징
IaaSOS부터 사용자 직접 구성
PaaS애플리케이션 개발 환경 제공
SaaS서비스 형태로 제공되는 소프트웨어
