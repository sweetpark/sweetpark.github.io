[실기] (PART 11) 응용 SW기초 기술 활용

NOTE

정보처리기사 실기 PART 11 — 운영체제, 네트워크, 데이터베이스 등 응용 SW 기초 기술 핵심 정리.

📌 개념

  • 운영체제

    • 하드웨어를 쉽게 이용할 수 있도록 인터페이스를 제공

  • 운영체제 특징

    • 사용자 편리성
    • 인터페이스 기능 담당
    • 스케줄링 담당
    • 자원 관리
    • 제어 기능

  • 운영체제 종류

    • 윈도우 : MS-DOS 멀티태스킹, GUI 환경
    • 유닉스 : 90% C언어 구현, 벨 연구소
    • 리눅스 : 오픈 소스 기반 운영체제
    • 맥 : 애플
    • 안드로이드 : 휴대용 장치

  • 운영체제 핵심 기능

    • 메모리관리
    • 프로세스 관리

  • 메모리 관리 기법

    • 반입기법 : 반입 시기 결정
    • 배치기법 : 어느 위치에 저장
    • 교체기법 : 어떤 프로세스를 제거
    • 할당기법 : 어떤 방법으로 할당
    • 상세내용
      • 메모리 배치기법
        • 최초적합
        • 최적적합
        • 최악적합
      • 메모리할당기법
        • 연속할당기법 : 주기억장치 공간내 인접되게 연속
        • 분산할당기법 : 하나의 프로세스를 여러개로 나누어 저장
      • 교체기법
        • FIFO
        • LRU : 가장 오랫동안 사용 안한 페이지 교체
        • LFU : 참조 횟수가 가장 적은 페이지 교체
        • OPT : 오랫동안 사용하지 않을 페이지 교체( 체크)
        • NUR : 최근에 사용하지 않은 페이지 교체 (체크)
        • SCR : 가장 오랫동안 있는 페이지중 자주 사용되는 페이지 교체 방지

  • 메모리 단편화

    • 내부단편화 : 적재후 남은 공간
    • 외부단편화 : 할당된 크기가 프로세스 크기보다 작아서 사용 못하는 공간

  • 페이징 기법의 문제점

    • 스레싱 : 페이지 교체하는데 시간을 더 많이 씀

    ⇒ 해결방법 : 워킹세트 (빈번한 페이지 주기억장치에 상주)

  • 지역성

    • 시간 지역성 : 최근 사용되었던 기억장소 집중적 액세스
    • 공간 지역성 : 참조된 메모리 근처 액세스
    • 순차 지역성 : 데이터가 순차적으로 액세스

  • 프로세스상태

    • 생성 → 준비 → 실행 → 대기 → 완료
    • 준비 → 실행 : 디스패치
    • 실행 → 준비 : 타이머 런 아웃(할당시간초과)
    • 실행 → 대기 : 블록 (입출력 발생)
    • 대기 → 준비 : 웨이크업

  • 선점형 스케줄링

    • 라운드로빈 : 같은 크기의 CPU 할당
    • SRT : 가장 짧은 시간이 소요되는 프로세스 먼저 수행
    • 다단계 큐 : 여러개 큐
    • 다단계 피드백 큐 : FIFO + 라운드로빈

  • 비선점형

    • 우선순위
    • 기한부 : 기한 내에 완료
    • SJF : 가장 짧은 작업부터 수행, 기아현상 발생
    • FCFS : FIFO알고리즘
    • HRN : 현재 응답률이 가장 높은 것 선택, 기아현상 해결 (HRN 우선순위 = (대기시간+서비스시간)/서비스시간

  • 교착상태 발생조건

    • 상호배제 : 배타적 점유
    • 점유와 대기 : 점유하고 있으면 또다른 자원 요청하여 대기상태
    • 비선점 : 오직 점유한 프로세스만 해제 가능함
    • 환형대기 : 하나의 원형을 구성

  • 교착상태 해결방법

    • 예방 : 점유 자원 해제 후 새 자원 요청
    • 회피 : 은행가 알고리즘
    • 발견 : 시스템 상태를 감시, 교착상태 검사
    • 복구 : 교착상태가 없어질때까지 프로세스 kill

  • 디스크 스케줄링 종류

    • FCFS : FIFO
    • SSTF : 탐색거리가 가장 짧은 것부터
    • SCAN : 한쪽으로 끝까지 이동후 다시 역으로 돌아옴
    • C-SCAN : 바깥쪽에서 안쪽으로 움직이면서 짧은 탐색거리
    • N-STEP SCAN : 진행중에 들어온 요청은 모아두었다가, 나중에 반대로 돌아가면서 처리
    • LOOK : 한쪽 방향으로 가다 요청이 없으면 반대로 돌아감
    • SLTF : 회전지연시간을 최적화

  • 가상화 기술요소

    • 컴퓨팅 가상화 : 리소스를 가상화 (ex_ 하이퍼바이저)
    • 스토리지 가상화 : 분산파일시스템
    • I/O가상화 : 미들웨어 계층 (ex_ 가상 네트워크 인터페이스 카드)
    • 도커
    • 분산처리 기술
    • 네트워크 가상화 기술 : 가상 네트워크 지원

  • 클라우드 컴퓨팅 유형

    • 인프라형 서비스 (IAAS)
    • 플랫폼형 서비스 (PAAS)
    • 소프트웨어형 서비스 (SAAS)

  • 네트워크

    • WAN
    • LAN

  • OSI 7계층

    • 응용 계층 : 응용서비스 연결
    • 표현계층 : 암/복호화, 압축
    • 세션 계층 :연결접속, 동기제어
    • 전송계층 : 신뢰성 통신
    • 네트워크 계층 : 최적화된 경로 제공
    • 데이터링크 계층 : 전송 오류 제어
    • 물리계층 : 0과 1비트 정보 변환

  • 원거리 통신망 연결 기술 (WAN)

    • 전용 회선 방식 : 점대점 방식
    • 회선 교환 방식 : 물리적 전용선을 활용 (동일 경로로 전달)
    • 패킷 교환 방식 : X.25, 프레임릴레이에 사용

  • 전송매체 접속제어(반이중 방식)

    • CSMA/CD : 현재 채널이 사용중인지 체크후 사용 안하면 전송
    • CSMA/CA : 현재 채널이 사용중인지 체크후 비어있으면 임의시간을 기다린후 전송

  • 프로토콜의 3요소

    • 구문 : 데이터형식, 코딩, 신호레벨 등을 규정
    • 의미 : 조정과 에러처리위한 규정
    • 타이밍 : 속도조절

  • 데이터링크 계층 프로토콜 (2계층)

    • HDLC : 동기식 비트 중심 데이터링크프로토콜
    • 프레임 릴레이 : 데이터 프레임들의 중계기능과 다중화 기능만 수행
    • PPP : 두 통신 노드 직접적인 연결
    • ATM : 53바이트 셀 단위로 전달하는 비동기식 시분할 다중화 방식 (패킷)

  • 데이터링크 계층 오류제어 (2계층)

    • 전진 오류 수정(FEC) : 해밍코드 방식과 상승코드 방식
    • 후진 오류 수정(BEC) : 패리티 검사, CRC, 블록합 검사

  • 데이터링크 자동 반복 요청방식 종류 (2계층)

    • stop-and-wait ARQ 방식 : 한 개 프레임 전송 후 응답 대기
    • Go back N ARQ 방식 : 여러개 프레임 전송 NAK을 수신하게 되면, 오류인 지점부터 다시 보냄
    • Selective Reapeat ARQ : 에러가 발생한 프레임만 재전송

  • 네트워크 계층 프로토콜 (3계층)

    • IP
    • ARP
    • RARP
    • ICMP
    • IGMP
    • 라우팅 프로토콜

  • 서브넷팅 종류

    • FLSM : 서브넷 길이 고정적 사용
    • VLSM : 서브넷 길이 가변적 사용

  • 라우팅 프로토콜 (3계층)

    • IGP (내부 라우팅 프로토콜) : RIP, IGRP, OSPF, EIGRP
    • EGP (외부 라우팅 프로토콜) : BGP
    • 상세내용
      • IGP
        • RIP : 15홉 제한, UDP 사용, 벨만포드알고리즘 사용
        • OSPF : 링크상태알고리즘, 다익스트라알고리즘
      • EGP
        • BGP : 경로 벡터 알고리즘 사용

  • 라우팅 알고리즘 유형

    • 거리벡터알고리즘 : 벨만 포드 알고리즘
    • 링크상태알고리즘 : 다익스트라 알고리즘 사용

  • 세션 계층 프로토콜(4계층)

    • RPC : 원격 프로시저 호출
    • NetBIOS : 응용계층의 애플리케이션 프로그램에게 API 제공

  • 표현 계층 프로토콜 (6계층)

    • JPEG, MPEG

  • 응용 계층 프로토콜(7계층)

    • HTTP, FTP, SMTP, POP3, IMAP
  • 네트워크 전달방식
    • 패킷 교환 방식 : X.25, 프레임 릴레이, ATM(비동기 전송모드)
      • 데이터그램 방식 : 독립적 전송
      • 가상회선 방식 : 통신경로를 미리 설정하여 전송
    • 서킷 교환 방식 : 영상, 비디오
  • 네트워크 구조
    • 애드 혹 네트워크 : 긴급 구조, 긴급회의, 전쟁터에서의 군사 네트워크
  • 네트워크 설치구조
    • 버스형
    • 트리형
    • 링형
    • 성형(star)
  • 신기술 용어
    • 네트워크 관련 신기술 용어
      • SDN : 네트워크 제어부 ,전달부 분리
      • NFV : 범용 하드웨어 + 가상화 기술
      • WI-SUN : 스마트 그리드와 연결 (무선 네트워크 효율적 사용)
      • NFC : 비접촉식 무선 통신 기술
      • 스몰 셀 : 좁은 커버리지를 가지는 소형 기지국
      • 블루투스 : 10m이내 근거리 디바이스간 통신 지원
      • Zing : 키오스크에 갖다 대면 원하는 데이터 바로 가져옴
      • BcN : 끊김없이 안전하게 이용
      • C-V2X : 도로 등 인프라가 구축된 사물과 정보 교환할 수 있는 통신 기술
      • 메시 네트워크 : 기존 무선 랜의 극복, 그물 모양 네트워크
      • UWB : 낮은 전력을 사용하여 데이터전송
      • UsN : 환경 정보 탐지
      • WBAN : 신체 접촉 근거리 무선 네트워크
      • NDN : IP 주소 대신 Data 이름을 활용
      • 네트워크 슬라이싱 : 5G 핵심기술
      • NOMA : 비직교 다중 접속 기술
      • MEC : 모바일 코어 망의 혼잡 완화
      • 사물인터넷
      • MQTT : 경량 메시지
      • COAP : M2M사이에서 송수신을 비동기적 전송
      • Zigbee : 저전력, 저속, 저비용의 근거리 무선통신
      • 스마트 그리드 : 에너지 이용효율 극대화
    • 소프트웨어 관련 신기술 용어
      • 인공지능
      • 기계학습
      • 가상현실(VR) : 실제와 유사하지만 실제가 아닌
      • 증강현실(AR) : 실제로 존재하는 환경
      • 혼합현실(MR) : 물리적 환경과 가상환경을 혼합
      • 블록체인 : 분산데이터베이스 형태로 데이터 기록리스트인 블록을 연결
      • BaaS : 블록체인 개발환경을 클라우드로 서비스
      • CPS : 실시간으로 물리적 요소들을 제어
      • 디지털 트윈 : 실제 물리적 자산 대신 가상화
      • 서비스 지향 아키텍처 (SOA)
      • 메시업 : 서로 다른 웹 콘텐츠를 조합
      • 그레이 웨어 : 합법적 프로그램이면서 사용자를 귀찮게 함
      • 텐서플로 : 기계학습 오픈소스
      • 파스타 : NIA 주도로 개발된 개방형 클라우드 컴퓨팅 플랫폼
      • 메타버스 : 가상, 초월과세계,우주 합성어
        • SDS : 물리적 디스크 드라이브를 가상화 기술을 적용하여 논리적인 스토리지
    • 인프라 신기술 용어
      • SDDC : 모든 하드웨어가 가상화
      • HACMP : 공유 디스크를 중심으로 클러스터링으로 연결
      • 도커
      • 하이퍼바이저
      • 쿠버네티스
      • 서버리스 컴퓨팅 : MSA,Baas,Faas와 같이 서버 없는것과 같이 처리하는 컴퓨팅기술
    • DB관련 신기술 용어
      • 하둡 : 분산 컴퓨팅 플랫폼
      • HDFS : 대용량 파일을 분산된서버에 저장하고 빠르게 처리
      • 맵리듀스 : 하둡으로 대표되는 소프트웨어 프레임워크
      • 스쿱 : RDBMS에서 HDFS로 데이터 수집
      • NOSQL : 조인연산 불가, 수평적 확산
      • 다크데이터 : 분석에 활용되지는 않는 다량의 데이터
      • 데이터 마이닝 : 일정한 패턴 찾기
      • 데이터 웨어하우스 : 데이터베이스에 축적된 데이터를 공통형식으로 변환
      • 데이터 마트 : 데이터 웨어하우스에서 데이터를 꺼내 사용자에게 제공
      • 메타데이터 : 일련의 데이터를 정의하고 설명해주는 데이터
      • 디지털아카이빙 : 장기간 관리
      • 마이데이터 : 정보 주체 중심의 데이터 활용체계
