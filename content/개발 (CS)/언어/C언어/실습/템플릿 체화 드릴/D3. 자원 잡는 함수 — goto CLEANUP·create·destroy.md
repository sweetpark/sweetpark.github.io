# D3. 자원 잡는 함수 — `goto CLEANUP` · create · destroy

> **쓰는 템플릿**: [1. 기본 골격](../../c코드%20템플릿/1.%20기본%20골격%20—%20리턴코드·가드매크로·단일출구%20cleanup.md) 5-2 · 5-3 절
> **목표 시간**: 1회차 45분 / 2회차 30분 / **3회차 20분**
> **누수는 "언젠가" 가 아니라 "항상 실패 경로에서" 난다.** 이 드릴은 실패 경로만 집중적으로 친다.

---

## 0. 이 드릴로 체화할 것

```c
int f(const in_t *in, out_t *out)
{
    int   ret = RET_FAIL;        /* ① 실패가 기본값. 성공은 맨 끝에서만 덮어쓴다 */
    char *buf = NULL;            /* ② 포인터는 전부 NULL, fd 는 -1 로 선언 */
    FILE *fp  = NULL;
    int   fd  = -1;

    CHK_PTR(in);                 /* ③ 자원 잡기 전 → 즉시 return (goto 아님) */
    CHK_PTR(out);
    memset(out, 0x00, sizeof(*out));

    buf = calloc(1, N);
    CHK_PTR_GOTO(buf, CLEANUP);  /* ④ 첫 자원을 잡은 뒤부터는 전부 goto */

    ret = RET_OK;                /* ⑤ 끝까지 왔을 때만 성공 */
CLEANUP:
    SAFE_FCLOSE(fp);             /* ⑥ 잡은 역순 */
    SAFE_FREE(buf);
    SAFE_CLOSE(fd);
    if (ret != RET_OK) memset(out, 0x00, sizeof(*out));   /* ⑦ 실패면 출력을 비운다 */
    return ret;
}
```

**①②⑤⑥이 한 세트다.** 하나만 빠져도 누수 아니면 double free 가 된다.

### 소유권 규칙 — create / destroy

| 상황 | 누가 해제하나 |
| :--- | :--- |
| `_create()` 가 `RET_OK` | **호출부**가 `_destroy()` 해야 한다 |
| `_create()` 가 실패 | **내부에서 전부 정리하고** `*out_obj = NULL` 로 둔다. 호출부는 아무것도 안 한다 |
| `_destroy(NULL)` | **합법이어야 한다.** 아무 일도 안 하고 리턴 |
| `_destroy()` 를 두 번 | 호출부가 포인터를 NULL 로 만들게 **`_destroy(obj_t **)`** 로 받는 것도 방법 |

## 1. 요구사항 — 변형 A: 설정 파일 로더

> [!QUOTE] 요구사항서 (발췌)
> `key=value` 형식 설정 파일을 읽어 설정 객체를 만든다.
> - 한 줄 최대 **255자**. `#` 로 시작하는 줄과 빈 줄은 **무시**.
> - `key` 는 최대 31자, `value` 는 최대 127자. 앞뒤 공백은 **제거**.
> - 같은 key 가 두 번 나오면 **나중 것이 이긴다**.
> - 항목 개수 상한은 **없다** (동적 확장).
> - **필수 키**: `listen_port`(1~65535), `worker_num`(1~64). 없으면 로딩 실패.
> - 파일이 없으면 `RET_IO_ERROR`, 형식 위반은 `RET_BAD_FORMAT`, 할당 실패는 `RET_NO_MEM`.
> - 조회 API: `cfg_get_str(cfg, key, &out)` / `cfg_get_int(cfg, key, &out)`.

### 미션

1. `cfg_create(const char *path, cfg_t **out_cfg)` — **소유권을 넘기는 생성 함수**.
2. `cfg_destroy(cfg_t *cfg)` — `NULL` 안전.
3. 항목 배열을 **2배씩 확장**(`realloc`)하되, **realloc 실패 시 원본을 잃지 않게**.
4. `cfg_get_int()` 는 숫자가 아니면 `RET_BAD_FORMAT`.

### 회차별 변형

| 회차 | 변형 | 바뀌는 조건 |
| :--- | :--- | :--- |
| **A (1회차)** | 설정 파일 로더 | `FILE*` + 동적 배열 |
| **B (2회차)** | **세션 컨텍스트 생성기** | 객체 안에 **동적 자원 3개**(버퍼 / 문자열 배열 / mutex). 중간 실패 시 **잡은 것만** 역순 해제 |
| **C (3회차)** | **두 파일 병합기** | 자원 4종(`open` fd 2개 + `FILE*` + 버퍼) 혼재. `fd` 는 `-1`, `FILE*` 는 `NULL` 로 구분됨을 몸으로 |

## 2. 핵심 검증 — 실패 주입(Fault Injection)

> [!IMPORTANT] 이 드릴의 진짜 시험은 이것이다
> 정상 동작은 쉽다. **N번째 `malloc` 이 실패했을 때 누수가 0인지**를 봐야 한다.

```c
/* test_alloc.h — 시험 빌드에서만 malloc 을 가로챈다 */
extern int g_alloc_fail_at;     /* -1: 항상 성공, k: k번째 호출을 실패시킴 */
extern int g_alloc_count;

static inline void *t_calloc(size_t n, size_t sz)
{
    if (g_alloc_fail_at >= 0 && g_alloc_count == g_alloc_fail_at) {
        g_alloc_count++;
        return NULL;                    /* 이번 할당만 실패 */
    }
    g_alloc_count++;
    return calloc(n, sz);
}

#ifdef UNIT_TEST
#  define CALLOC(_n, _sz)  t_calloc((_n), (_sz))
#else
#  define CALLOC(_n, _sz)  calloc((_n), (_sz))
#endif
```

```c
/* 시험: 0번째부터 20번째 할당까지 하나씩 실패시켜본다 */
static void test_alloc_fail_all(void)
{
    int k = 0;

    for (k = 0; k < 20; k++) {
        cfg_t *cfg = NULL;
        int    ret = 0;

        g_alloc_fail_at = k;
        g_alloc_count   = 0;

        ret = cfg_create("test/sample.cfg", &cfg);

        /* 실패했으면 cfg 는 반드시 NULL 이어야 한다 */
        if (ret != RET_OK) T_EQ_INT(cfg == NULL, 1);
        cfg_destroy(cfg);               /* 성공했으면 여기서 해제 */
    }
    g_alloc_fail_at = -1;
}
```

```bash
clang -Wall -Wextra -Werror -std=c11 -g -DUNIT_TEST \
      -fsanitize=address,undefined d3_resource/src/*.c d3_resource/test/*.c -o build/d3
./build/d3
```

**ASan 리포트에 `LEAK` 가 한 줄이라도 나오면 0점이다.** 이 루프를 통과하면 그 함수는 실무에 나가도 된다.

## 3. 자가 채점표 (100점)

| 항목 | 배점 | 체크 |
| :--- | :--- | :--- |
| `int ret = RET_FAIL;` 로 시작 | 10 | ☐ |
| 모든 자원 변수를 **선언과 동시에** `NULL` / `-1` | 10 | ☐ |
| 자원 잡기 **전** 검사는 즉시 return, **후**는 전부 `goto` | 15 | ☐ |

| 실패 시 `*out_obj = NULL` / `out` 초기화 | 10 | ☐ |

| **실패 주입 20회 전부 누수 0** | 20 | ☐ |

## 4. 자주 하는 실수

| 실수 | 증상 |
| :--- | :--- |
| `p = realloc(p, n)` | realloc 실패 시 **원본 포인터를 잃어버린다** → 확정 누수. `tmp` 로 받고 성공했을 때만 대입 |
| `CLEANUP` 앞에서 `return ret;` 을 추가로 함 | 그 경로만 해제를 건너뛴다. **출구는 하나** |
| 해제 순서를 잡은 순서대로 | 버퍼를 먼저 free 하고 그 버퍼를 쓰는 `fclose` 후처리를 하면 use-after-free |
| `_destroy()` 안에서 멤버만 free 하고 객체 자체를 안 함 | 객체 크기만큼 매번 샌다 |
| 성공했는데 `ret` 을 안 바꿈 | `RET_FAIL` 로 시작했으니 **정상인데 실패로 리턴**된다. 제일 흔한 자책골 |
| `goto CLEANUP` 이 변수 선언을 건너뜀 | `-Wjump-misses-init` / C++ 에서는 컴파일 에러. **선언은 전부 함수 맨 위** |

## 5. 모범답안 (변형 A)

> [!success]- 다 치고 나서 열 것 — `cfg.c` 핵심부
> ```c
> #define CFG_KEY_MAX    31
> #define CFG_VAL_MAX    127
> #define CFG_LINE_MAX   255
>
> typedef struct { char key[CFG_KEY_MAX + 1]; char val[CFG_VAL_MAX + 1]; } cfg_item_t;
>
> struct cfg_s {                       /* 불투명: 헤더에는 typedef 만 노출 */
>     cfg_item_t *items;
>     size_t      num;
>     size_t      cap;
> };
>
> /* ── 항목 추가: 중복 키는 덮어쓰기, 모자라면 2배 확장 ───────── */
> static int cfg_put(cfg_t *cfg, const char *key, const char *val)
> {
>     size_t      i   = 0;
>     cfg_item_t *tmp = NULL;
>
>     CHK_PTR(cfg); CHK_PTR(key); CHK_PTR(val);
>
>     for (i = 0; i < cfg->num; i++) {                 /* 나중 것이 이긴다 */
>         if (strcmp(cfg->items[i].key, key) == 0) {
>             snprintf(cfg->items[i].val, sizeof(cfg->items[i].val), "%s", val);
>             return RET_OK;
>         }
>     }
>
>     if (cfg->num == cfg->cap) {
>         size_t new_cap = (cfg->cap == 0) ? 8 : cfg->cap * 2;
>
>         tmp = realloc(cfg->items, new_cap * sizeof(*tmp));   /* ★ tmp 로 받는다 */
>         if (tmp == NULL) {                                   /*   원본은 그대로 살아있다 */
>             LOG_ERR("realloc %zu failed", new_cap);
>             return RET_NO_MEM;
>         }
>         cfg->items = tmp;
>         cfg->cap   = new_cap;
>     }
>
>     snprintf(cfg->items[cfg->num].key, CFG_KEY_MAX + 1, "%s", key);
>     snprintf(cfg->items[cfg->num].val, CFG_VAL_MAX + 1, "%s", val);
>     cfg->num++;
>     return RET_OK;
> }
>
> /* ── 생성: 소유권을 호출부로 넘긴다 ─────────────────────────── */
> int cfg_create(const char *path, cfg_t **out_cfg)
> {
>     int    ret  = RET_FAIL;          /* ① */
>     cfg_t *cfg  = NULL;              /* ② */
>     FILE  *fp   = NULL;
>     char  *line = NULL;
>
>     CHK_PTR(path);                   /* ③ 자원 잡기 전 → 즉시 return */
>     CHK_PTR(out_cfg);
>     *out_cfg = NULL;                 /*    실패해도 호출부가 쓰레기를 안 보게 */
>
>     cfg = CALLOC(1, sizeof(*cfg));   /* ④ 여기부터 goto */
>     CHK_PTR_GOTO(cfg, CLEANUP);
>
>     line = CALLOC(1, CFG_LINE_MAX + 2);
>     CHK_PTR_GOTO(line, CLEANUP);
>
>     fp = fopen(path, "r");
>     CHK_COND_GOTO(fp != NULL, RET_IO_ERROR, CLEANUP);
>
>     while (fgets(line, CFG_LINE_MAX + 2, fp) != NULL) {
>         char *eq = NULL, *key = NULL, *val = NULL;
>
>         line[strcspn(line, "\r\n")] = '\0';          /* 개행 제거 */
>         key = trim(line);
>         if (key[0] == '\0' || key[0] == '#') continue;   /* 빈 줄 / 주석 */
>
>         eq = strchr(key, '=');
>         CHK_COND_GOTO(eq != NULL, RET_BAD_FORMAT, CLEANUP);
>
>         *eq = '\0';
>         val = trim(eq + 1);
>         key = trim(key);
>
>         CHK_COND_GOTO(key[0] != '\0', RET_BAD_FORMAT, CLEANUP);
>         CHK_COND_GOTO(strlen(key) <= CFG_KEY_MAX, RET_BAD_FORMAT, CLEANUP);
>         CHK_COND_GOTO(strlen(val) <= CFG_VAL_MAX, RET_BAD_FORMAT, CLEANUP);
>
>         CHK_RET_GOTO(cfg_put(cfg, key, val), CLEANUP);
>     }
>
>     /* 필수 키 검사 */
>     {
>         int port = 0, worker = 0;
>         CHK_RET_GOTO(cfg_get_int(cfg, "listen_port", &port), CLEANUP);
>         CHK_RET_GOTO(cfg_get_int(cfg, "worker_num",  &worker), CLEANUP);
>         CHK_COND_GOTO(port   >= 1 && port   <= 65535, RET_BAD_FORMAT, CLEANUP);
>         CHK_COND_GOTO(worker >= 1 && worker <= 64,    RET_BAD_FORMAT, CLEANUP);
>     }
>
>     *out_cfg = cfg;                  /* ★ 소유권 이전 */
>     cfg      = NULL;                 /* ★ 아래 CLEANUP 이 해제하지 않도록 끊는다 */
>     ret      = RET_OK;               /* ⑤ */
>
> CLEANUP:                             /* ⑥ 잡은 역순 */
>     SAFE_FCLOSE(fp);
>     SAFE_FREE(line);
>     cfg_destroy(cfg);                /*   성공 시엔 NULL 이므로 아무 일도 안 한다 */
>     return ret;
> }
>
> void cfg_destroy(cfg_t *cfg)
> {
>     if (cfg == NULL) return;         /* ★ NULL 안전 */
>     SAFE_FREE(cfg->items);
>     free(cfg);                       /*   객체 자체도 반드시 */
> }
> ```
>
> **눈여겨볼 점 3가지**
> 1. **`cfg = NULL;` 한 줄이 이 함수의 심장이다.** 성공 경로에서 소유권을 넘긴 뒤 로컬 포인터를 끊어야, 같은 `CLEANUP` 라벨을 성공·실패가 같이 쓸 수 있다.
> 2. `realloc` 은 **`tmp` 로 받는다.** 바로 대입하면 실패 시 원본을 잃는다.
> 3. `cfg_destroy` 를 `CLEANUP` 에서 쓰니 **부분적으로 만들어진 객체도 한 함수로 정리**된다. 해제 코드를 두 군데 쓰지 않는다.
