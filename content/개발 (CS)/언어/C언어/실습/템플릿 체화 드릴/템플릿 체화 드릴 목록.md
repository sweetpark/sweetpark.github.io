# 템플릿 체화 드릴 _index

> **목적은 "C를 배우는 것"이 아니다.**
> [c코드 템플릿](../../c코드%20템플릿/c코드%20템플릿%20목록.md)의 뼈대가 **생각하지 않아도 손에서 나오게** 만드는 것.
> 그래서 이 폴더의 드릴은 전부 같은 절차를 반복한다. **요구사항 한 장 → 표 3장 → 구조체 → 시그니처 → 뼈대 → 로직 → pack → 시험 3개.**

---

## 이 폴더와 옆 폴더(`실습/`)의 차이

| | [실습 가이드](../README.md) (기존) | **템플릿 체화 드릴** (이 폴더) |
| :--- | :--- | :--- |
| 출발점 | 개념 노트 (엔디안, atomic, epoll…) | **요구사항 한 장** (규격서 흉내) |
| 목표 | 그 개념이 동작하는 걸 본다 | **매번 같은 뼈대로 친다** |
| 성공 기준 | 돌아간다 | **안 보고 10분 안에 뼈대가 나온다** |
| 반복 | 1회 | **3회차 × 변형 3종** |

둘은 대체 관계가 아니다. 개념이 흔들리면 `실습/`, 손이 안 움직이면 여기.

## 반복 학습 방법 — 3회차 규칙

같은 드릴을 **세 번** 친다. 회차마다 **보는 것이 줄어든다.**

| 회차 | 볼 수 있는 것 | 하는 일 | 합격선 |
| :--- | :--- | :--- | :--- |
| **1회차 (모방)** | 템플릿 문서 전체 | 복붙하고 `{{ }}` 만 채운다 | 빌드 통과 + 시험 3개 통과 |
| **2회차 (재구성)** | **내가 만든 표 3장만** | 뼈대를 기억해서 친다. 막히면 그때만 연다 | 연 횟수 3회 이하 |
| **3회차 (재현)** | **아무것도 안 봄** | 백지에서 끝까지 | 목표 시간 안 + 자가채점 90점 |

그리고 **회차마다 요구사항을 바꾼다.** 각 드릴 노트에 변형 **A / B / C** 가 들어있다.
같은 문제를 세 번 치면 답을 외운 것이지 뼈대를 익힌 게 아니다.

### 간격 — 언제 다시 치나

```text
D+0  1회차(변형 A)  →  D+1  2회차(변형 B)  →  D+4  3회차(변형 C)  →  D+14  점검(랜덤 변형)
```

D+14 점검에서 **목표 시간을 넘기면 그 드릴은 2회차로 되돌린다.**

## 하루 루틴 (30분)

```text
[5분]  워밍업 D0 — 백지에 guard.h 치기. 매일 같은 것.
[20분] 오늘의 드릴 1개 — 요구사항 읽기 3분 / 표 3분 / 뼈대 2분 / 로직 나머지
[5분]  자가채점표 작성 + 회차 기록표에 시간·점수 적기
```

> [!IMPORTANT] 채점을 빼먹으면 반복이 안 쌓인다
> 드릴의 진짜 산출물은 코드가 아니라 **"어디서 막혔는지"** 다.
> 각 노트 맨 아래 **회차 기록표**에 막힌 지점을 한 줄로 남긴다. 그게 다음 회차의 목표가 된다.

## 작업 폴더 만들기

노트는 이 폴더, **코드는 vault 밖**에 둔다.

```bash
mkdir -p ~/cdrill/{d0_warmup,d1_pure,d2_model,d3_resource,d4_pack,d5_tlv,d7_daemon,d8_3gpp,d9_final}/{src,test}
mkdir -p ~/cdrill/common
```

### 공통 헤더 (한 번만 만들고 전 드릴에서 재사용)

`~/cdrill/common/` 에 [1번 템플릿](../../c코드%20템플릿/1.%20기본%20골격%20—%20리턴코드·가드매크로·단일출구%20cleanup.md)의
`common.h` · `guard.h` · `log.h` 를 놓는다. **단, D0 에서는 매번 백지에서 다시 친다.**

### 공통 Makefile

```makefile
# ~/cdrill/Makefile   사용법:  make D=d1_pure T=step1
CC       := clang
CFLAGS   := -Wall -Wextra -Werror -pedantic -std=c11 -g -Icommon
SAN      := -fsanitize=address,undefined -fno-omit-frame-pointer
D        ?= d1_pure
T        ?= main

SRC      := $(wildcard $(D)/src/*.c)
BIN      := build/$(D)_$(T)

all: run

build:
	@mkdir -p build

$(BIN): build $(SRC)
	$(CC) $(CFLAGS) $(SAN) $(SRC) -o $(BIN)

run: $(BIN)
	@echo "── run ──────────────────────────────"
	@./$(BIN)

# 위생 검사: 경고 0 + 새니타이저 0 이어야 통과
check: $(BIN)
	@./$(BIN) && echo "✅ PASS" || (echo "❌ FAIL"; exit 1)

clean:
	rm -rf build

.PHONY: all run check clean build
```

> [!WARNING] `-Werror` 를 빼지 말 것
> 경고를 켜 두고 무시하는 습관이 제일 나쁘다. **경고 = 빌드 실패** 로 만들어야 손이 바뀐다.
> 정적분석기를 따로 돌리기 전에, `-Wall -Wextra -Werror -pedantic` 이 이미 절반을 잡아준다.

## 자가 채점 공통 기준 (100점)

각 드릴 노트의 채점표는 이 배점을 따른다.

| 항목 | 배점 | 0점 처리되는 경우 |
| :--- | :--- | :--- |
| **뼈대 정확도** | 30 | 가드가 없다 / `goto CLEANUP` 없이 중간 `return` 을 했다 |
| **출력 초기화** | 10 | `memset(out, 0x00, sizeof(*out))` 을 빼먹었다 |
| **에러 전파** | 10 | 하위 에러코드를 `RET_FAIL` 로 덮어썼다 |
| **자원 해제** | 15 | 새니타이저에 누수 1건이라도 있다 |
| **시험 3개** | 15 | 정상 / 경계 / NULL 중 하나라도 없다 |
| **빌드 위생** | 10 | 경고 1개라도 있다 |
| **시간** | 10 | 목표 시간의 2배 초과 |

**90점 미만이면 그 회차는 통과가 아니다.** 같은 회차를 다시 친다.
