# D1. 자원 없는 함수 — 가드 · 단일출구 · 시험 3개

> **쓰는 템플릿**: [1. 기본 골격](../../c코드%20템플릿/1.%20기본%20골격%20—%20리턴코드·가드매크로·단일출구%20cleanup.md) 5-1 절
> **목표 시간**: 1회차 30분 / 2회차 18분 / **3회차 12분**
> 실무 함수의 **80%가 이 모양**이다. `malloc` 도 파일도 없다. 그래서 제일 먼저 체화한다.

---

## 0. 이 드릴로 체화할 것

```c
int f(const in_t *in, out_t *out)
{
    CHK_PTR(in);                          /* ① 인자 검사 = 첫 줄 */
    CHK_PTR(out);
    CHK_RANGE(in->x, MIN, MAX);

    memset(out, 0x00, sizeof(*out));      /* ② 출력은 항상 초기화부터 */

    /* ③ 여기서만 생각한다 */

    return RET_OK;                        /* ④ 성공은 맨 끝 한 곳 */
}
```

**이 네 줄의 순서가 흔들리지 않는 게 목표다.** 로직이 틀린 건 괜찮다. 순서가 틀리면 실패.

---

## 1. 요구사항 — 변형 A: MSISDN 정규화

> [!QUOTE] 요구사항서 (발췌)
> 가입자가 입력한 전화번호 문자열을 **E.164 숫자열**로 정규화한다.
> - 입력 문자열은 최대 31자. 허용 문자는 **숫자 / `-` / 공백 / `+`**.
> - `+` 는 **맨 앞에만** 올 수 있다.
> - `-` 와 공백은 **무시**한다.
> - 서비스는 **단일 국가** 전용이다. 기본 국가코드(`def_cc`)와 다른 국가번호가 오면 **미지원**으로 처리한다.
> - `+` 없이 `0` 으로 시작하면 **선행 `0` 을 떼고** 국가코드를 붙인다.
>   예) `"010-1234-5678"`, `def_cc=82` → `"821012345678"`
> - 결과 숫자열이 **15자를 넘으면** 규격 위반이다.
> - 출력으로 **국가코드**와 **국내번호(NSN)** 도 따로 돌려준다.

### 회차별 변형

| 회차 | 변형 | 요구사항 |
| :--- | :--- | :--- |
| **A (1회차)** | MSISDN 정규화 | 위 내용 |
| **B (2회차)** | **IMSI 분해** | 15자리 숫자 IMSI 를 `MCC(3)` + `MNC(2 또는 3)` + `MSIN` 으로 분해. MNC 자릿수는 **MCC 별 표**로 판단(예: `450`→2, `310`→3). 숫자 외 문자·길이 위반은 `RET_BAD_FORMAT` |
| **C (3회차)** | **타임스탬프 검증** | `"YYYYMMDDhhmmss"` 14자를 검증해 `struct tm` + `time_t` 로 변환. 윤년·월별 일수·시분초 범위 전부 검사. 변환 결과가 **음수이거나 2038-01-19 이후**면 `RET_NOT_SUPPORTED` |

## 3. 제출물

```text
d1_pure/src/msisdn.h     구조체 2개 + 함수 선언 1개
d1_pure/src/msisdn.c     함수 구현
```

### 시험 3개 — 이 형태를 고정한다

```c
static int g_fail = 0;

#define T_EQ_INT(_got, _exp)                                            \
    do {                                                                \
        int _g = (int)(_got), _e = (int)(_exp);                         \
        if (_g != _e) { g_fail++;                                       \
            printf("  X %s:%d  got=%d exp=%d\n",                        \
                   __func__, __LINE__, _g, _e); }                       \
    } while (0)

#define T_EQ_STR(_got, _exp)                                            \
    do {                                                                \
        if (strcmp((_got), (_exp)) != 0) { g_fail++;                    \
            printf("  X %s:%d  got=\"%s\" exp=\"%s\"\n",                \
                   __func__, __LINE__, (_got), (_exp)); }               \
    } while (0)

static void test_normal(void)      /* 1) 정상: 대표 입력 1개 */
{
    msisdn_req_t in  = { .in_raw = "010-1234-5678", .def_cc = 82 };
    msisdn_rsp_t out;

    T_EQ_INT(msisdn_normalize(&in, &out), RET_OK);
    T_EQ_STR(out.e164, "821012345678");
    T_EQ_STR(out.nsn,  "1012345678");
    T_EQ_INT(out.cc, 82);
}

static void test_edge(void)        /* 2) 경계: 최대/최소/한 칸 넘김 */
{
    msisdn_req_t in  = { .in_raw = "+8210123456789012", .def_cc = 82 };
    msisdn_rsp_t out;

    T_EQ_INT(msisdn_normalize(&in, &out), RET_BAD_FORMAT);  /* 15자 초과 */

    snprintf(in.in_raw, sizeof(in.in_raw), "01-0-1234-5678");
    T_EQ_INT(msisdn_normalize(&in, &out), RET_OK);          /* '-' 는 전부 무시 */

    snprintf(in.in_raw, sizeof(in.in_raw), "010+12345678");
    T_EQ_INT(msisdn_normalize(&in, &out), RET_BAD_FORMAT);  /* '+' 가 중간 */

    snprintf(in.in_raw, sizeof(in.in_raw), "+8112345678");
    T_EQ_INT(msisdn_normalize(&in, &out), RET_NOT_SUPPORTED); /* 다른 국가 */
}

static void test_null(void)        /* 3) NULL: 인자 하나씩 NULL */
{
    msisdn_req_t in  = { .in_raw = "01012345678", .def_cc = 82 };
    msisdn_rsp_t out;

    T_EQ_INT(msisdn_normalize(NULL, &out), RET_INVALID_ARG);
    T_EQ_INT(msisdn_normalize(&in, NULL), RET_INVALID_ARG);
}

int main(void)
{
    test_normal(); test_edge(); test_null();
    printf(g_fail ? "FAIL %d\n" : "PASS\n", g_fail);
    return g_fail ? 1 : 0;
}
```

> [!TIP] 시험을 먼저 쓰면 표 3장이 저절로 완성된다
> `test_edge()` 를 쓰다 보면 "어? 이 경우는 뭘 리턴하지?" 가 나온다. **그게 표 ③에 빠진 행이다.**

## 5. 자주 하는 실수

| 실수 | 왜 문제인가 |
| :--- | :--- |
| `out` 을 초기화 안 하고 중간에 실패 | 호출부가 **쓰레기 값을 읽는다.** 실패해도 `out` 은 "빈 값"이어야 한다 |
| `char buf[15]` 에 15자 결과를 담음 | **`+1`** 을 잊었다. 문자열은 **항상 `MAX+1`** |
| 문자 검사에 `isdigit(c)` 를 그냥 씀 | `char` 가 음수일 때 UB. `isdigit((unsigned char)c)` 로 캐스팅 |
| 길이 검사를 `strlen` 결과로만 함 | 입력이 널 종단이 아닐 수 있다. 루프 상한에 `sizeof` 를 같이 건다 |
| 실패인데 `RET_FAIL` 하나로 뭉뚱그림 | 로그만 보고 원인을 못 찾는다. **에러 표의 행 = 리턴코드 1개** |

## 6. 모범답안 (변형 A)

> [!success]- 다 치고 나서 열 것 — `msisdn.h` / `msisdn.c`
> **헤더 (`msisdn.h`)**
> ```c
> #define MSISDN_LEN_MAX  15
>
> typedef struct {
>     char     in_raw[32];                 /* 입력 원문 (널 포함 32) */
>     uint16_t def_cc;                     /* 기본 국가코드 1~999 */
> } msisdn_req_t;
>
> typedef struct {
>     char     e164[MSISDN_LEN_MAX + 1];   /* 숫자만, '+' 없음.  +1 필수 */
>     char     nsn [MSISDN_LEN_MAX + 1];
>     uint16_t cc;
>     uint8_t  len;
> } msisdn_rsp_t;
>
> int msisdn_normalize(const msisdn_req_t *in, msisdn_rsp_t *out);
> ```
>
> **구현 (`msisdn.c`)**
> ```c
> #include "common.h"
> #include "log.h"
> #include "guard.h"
> #include "msisdn.h"
>
> static int is_allowed_char(char c)
> {
>     return (c >= '0' && c <= '9') || c == '-' || c == ' ' || c == '+';
> }
>
> int msisdn_normalize(const msisdn_req_t *in, msisdn_rsp_t *out)
> {
>     char        digits[64];
>     char        cc_str[8];
>     size_t      n = 0, i = 0, cc_len = 0;
>     int         has_plus = 0;
>     const char *nsn = NULL;
>
>     CHK_PTR(in);
>     CHK_PTR(out);
>     CHK_RANGE(in->def_cc, 1, 999);
>
>     memset(out, 0x00, sizeof(*out));
>     memset(digits, 0x00, sizeof(digits));
>
>     /* 1) 허용 문자 검사 + 숫자만 추출 */
>     for (i = 0; i < sizeof(in->in_raw) && in->in_raw[i] != '\0'; i++) {
>         char c = in->in_raw[i];
>
>         if (!is_allowed_char(c)) {
>             LOG_ERR("bad char 0x%02X at %zu", (unsigned char)c, i);
>             return RET_BAD_FORMAT;
>         }
>         if (c == '+') {
>             if (i != 0) {                       /* 맨 앞에만 허용 */
>                 LOG_ERR("'+' at %zu (must be head)", i);
>                 return RET_BAD_FORMAT;
>             }
>             has_plus = 1;
>             continue;
>         }
>         if (c == '-' || c == ' ') continue;     /* 구분자는 무시 */
>
>         if (n >= sizeof(digits) - 1) return RET_BAD_FORMAT;
>         digits[n++] = c;
>     }
>     if (n == 0) { LOG_ERR("no digit"); return RET_BAD_FORMAT; }
>
>     /* 2) 국가코드 분리 */
>     cc_len = (size_t)snprintf(cc_str, sizeof(cc_str), "%u", in->def_cc);
>
>     if (has_plus) {
>         if (strncmp(digits, cc_str, cc_len) != 0) {
>             LOG_ERR("foreign cc: %s (def=%s)", digits, cc_str);
>             return RET_NOT_SUPPORTED;           /* 단일 국가 서비스 */
>         }
>         nsn = digits + cc_len;
>     } else if (digits[0] == '0') {
>         nsn = digits + 1;                       /* 선행 0 제거 */
>     } else if (n > cc_len && strncmp(digits, cc_str, cc_len) == 0) {
>         nsn = digits + cc_len;                  /* 이미 82... 로 시작 */
>     } else {
>         nsn = digits;
>     }
>     if (nsn[0] == '\0') { LOG_ERR("empty nsn"); return RET_BAD_FORMAT; }
>
>     /* 3) 조립 + 길이 검증 */
>     if (cc_len + strlen(nsn) > MSISDN_LEN_MAX) {
>         LOG_ERR("e164 too long: %zu", cc_len + strlen(nsn));
>         return RET_BAD_FORMAT;
>     }
>
>     out->cc  = in->def_cc;
>     out->len = (uint8_t)(cc_len + strlen(nsn));
>     snprintf(out->nsn,  sizeof(out->nsn),  "%s", nsn);
>     snprintf(out->e164, sizeof(out->e164), "%s%s", cc_str, nsn);
>
>     return RET_OK;
> }
> ```
>
> **눈여겨볼 점 4가지**
> 1. 실패 경로가 전부 **가드 또는 명시적 `return RET_XXX`** — 뒷정리할 자원이 없으니 `goto` 를 쓰지 않는다.
> 2. 루프 상한이 `i < sizeof(in->in_raw)` — **널 종단을 믿지 않는다.**
> 3. `snprintf` 만 쓴다. `strcpy` 는 한 번도 안 나온다.
> 4. 에러 표가 4행이면 리턴코드도 4종(`INVALID_ARG` / `BAD_FORMAT` / `NOT_SUPPORTED`)으로 나뉜다.
