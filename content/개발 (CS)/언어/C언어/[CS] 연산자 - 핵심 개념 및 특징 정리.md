# 연산자

> [!NOTE]
> C 언어 연산자의 종류와 분류 정리.

> [!NOTE]
> 원문을 AI가 검토·보강함(사실 확인 권장).

## 📌 개념

### 포인터 연산자

- `*` : 역참조(간접) 연산자 — 주소가 가리키는 위치의 값을 추출
- `&` : 주소 연산자 — 변수의 메모리 주소를 반환

### C 연산자 분류

| 구분 | 연산자 | 설명 |
| --- | --- | --- |
| 산술 | `+ - * / %` | 사칙연산, `%`는 나머지 |
| 관계 | `== != > < >= <=` | 비교 결과로 참(1)/거짓(0) 반환 |
| 논리 | `&& \|\| !` | 논리곱/논리합/부정, 단축 평가(short-circuit) |
| 비트 | `& \| ^ ~ << >>` | 비트 단위 AND/OR/XOR/NOT/시프트 |
| 대입 | `= += -= *= /= %=` | 복합 대입 |
| 증감 | `++ --` | 전위(`++i`)/후위(`i++`) |
| 삼항 | `조건 ? A : B` | 조건 참이면 A, 아니면 B |
| 포인터/멤버 | `* & -> .` | 역참조/주소/구조체 멤버 접근 |
| `sizeof` | `sizeof(x)` | 타입·변수의 바이트 크기 |

- **연산자 우선순위**: 단항 > 산술 > 관계 > 비트 > 논리 > 삼항 > 대입 순이 대략적 흐름이며, 모호할 때는 괄호로 명시하는 것이 안전하다.
