# 예제 코드

> [!NOTE]
> `sprintf` + `strcat`로 "U-2021-NN," 형태의 문자열을 반복 생성하는 C 예제.

## 💻 예시

```c
#include <stdio.h>
#include <string.h>

int main(void){
    char str_plus[10];

    for(int i=1; i<73; i++){
        char str_[10]="U-2021-";
        sprintf(str_plus,"%02d,",i);
        strcat(str_,str_plus);
        printf("%s",str_);
    }

    return 0;
}
```
