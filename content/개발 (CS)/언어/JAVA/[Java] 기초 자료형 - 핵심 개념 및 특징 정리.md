# [기초] 자료형

> [!NOTE]
> Java 기본 자료형(primitive type)의 크기와 특징 정리. 배열 선언·초기화는 [(Java) 기초 배열 - 핵심 개념 및 특징 정리]([Java]%20기초%20배열%20-%20핵심%20개념%20및%20특징%20정리.md) 참고.

## 📌 개념

### 기본 자료형(primitive type)

> [!NOTE]
> - 자바에서 기본 자료형은 반드시 선언해야 함(타입 추론 없이 명시적 선언 필요)
> - OS/플랫폼에 따라 자료형 길이가 변하지 않음(JVM 명세로 고정)
> - 비객체 타입 — `null` 값을 가질 수 없음

| 자료형 | 크기 |
| --- | --- |
| byte | 1byte(8bit) |
| short | 2byte(16bit) |
| int | 4byte |
| long | 8byte |
| float | 4byte |
| double | 8byte |
| char | 2byte(16bit) |
| boolean | 1bit(JVM 명세상 정확한 크기는 미지정, 통상 1byte로 취급) |

### 배열 선언 문법(간단 참고)
- `[자료형][] [변수이름] = new [자료형][배열크기];`
- `[자료형] [변수이름][] = new [자료형][배열크기];`
- 예: `int[] score = new int[5];`
- 배열 선언·초기화·다차원 배열·ArrayList 등 상세 내용은 [(Java) 기초 배열 - 핵심 개념 및 특징 정리]([Java]%20기초%20배열%20-%20핵심%20개념%20및%20특징%20정리.md) 문서에 정리되어 있음.

## 💻 예시
```java
int[] score = new int[5];
byte b = 127;
long l = 10000000000L;
```
