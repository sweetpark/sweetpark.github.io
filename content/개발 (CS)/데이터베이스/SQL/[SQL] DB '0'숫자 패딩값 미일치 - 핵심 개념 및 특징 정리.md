# [DB] '0'숫자 패딩값 미일치

> [!NOTE]
> 파라미터의 0 패딩 값과 DB 저장값의 자릿수가 달라 조회가 실패하던 문제와 해결책.
> 실무에서 이관.

## 📌 개념

- 파라미터가 `'0100'`처럼 0 패딩된 형태로 전달되는데, DB에는 `'100'`처럼 앞자리 0이 제거된 형태로 저장되어 있으면 값이 일치하지 않아 조회가 실패한다.
- 해결: DB 컬럼 조회 시 `LPAD`로 자릿수를 맞춰 비교한다.

```sql
LPAD(COLUMN, 4, '0') = #{value}
```
