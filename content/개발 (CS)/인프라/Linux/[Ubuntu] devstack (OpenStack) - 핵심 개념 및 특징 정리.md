# devstack (OpenStack)

> [!NOTE]
> 원문을 AI가 검토·보강함(사실 확인 권장).
> DevStack은 OpenStack 공식 프로젝트에서 제공하는 개발/테스트용 설치 스크립트 모음으로, 단일 노드에 OpenStack 구성요소(Nova, Neutron, Keystone 등)를 빠르게 구성해준다.

## 📌 개념
- DevStack: `stack.sh` 스크립트 실행만으로 OpenStack 개발/테스트 환경을 자동 구성하는 도구.
- 운영 환경이 아닌 개발/PoC/학습 목적의 빠른 설치에 적합.
