# [명령어] ctags

> [!NOTE]
> `ctags`로 소스 심볼 인덱스(`tags`)를 생성해 vim에서 정의로 점프하는 방법 정리.

> [!NOTE]
> 원본이 간략하여 일반지식을 AI가 보강함(사실 확인 권장).

## 📌 개념

`ctags`는 소스코드의 함수·변수·매크로 등 심볼 위치를 인덱싱한 `tags` 파일을 생성하여, vim 등 에디터에서 정의로 즉시 점프할 수 있게 해주는 도구다.

## 💻 예시

```bash
# 현재 디렉터리 이하 재귀적으로 tags 생성
ctags -R .
```

### vim 태그 점프

- 함수 정의로 이동: `Ctrl + ]`
- 태그 검색/점프: `:ts [tag]`, `:tj [tag]` → 현재 위치가 stack에 push 됨
- 이전 위치로 복귀(POP): `:po`, `Ctrl + t`
