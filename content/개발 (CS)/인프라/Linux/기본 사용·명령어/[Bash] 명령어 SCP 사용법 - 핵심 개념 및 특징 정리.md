# [명령어] SCP 사용법

> [!NOTE]
> `scp`(secure copy)로 SSH 채널 위에서 로컬↔원격 간 파일을 암호화 전송하는 방법과 주요 옵션 정리.

> [!NOTE]
> 원본이 간략하여 일반지식을 AI가 보강함(사실 확인 권장).

## 📌 개념

`scp`(secure copy)는 SSH 채널 위에서 로컬↔원격 간 파일을 암호화 전송하는 명령이다.

| 옵션 | 설명 |
| --- | --- |
| `-r` | 디렉터리 재귀 복사 |
| `-P 포트` | SSH 포트 지정(대문자 P, 기본 22) |
| `-i 키파일` | 개인키 파일로 인증 |
| `-p` | 원본의 수정시간·권한 보존 |
| `-C` | 전송 중 압축 |
| `-v` | 상세 로그 출력 |

> [!TIP]
> 대용량·중단 재개가 필요하면 `rsync -avz`가 더 효율적이다.

## 💻 예시

```bash
# 로컬 -> 원격 (업로드)
scp [파일명] 계정명@[ip]:[원격경로]

# 원격 -> 로컬 (다운로드)
scp 계정명@[ip]:[원격경로] [로컬경로]

# 22000 포트, 키 인증으로 디렉터리 업로드
scp -r -P 22000 -i ~/.ssh/id_ed25519 ./dist user@10.0.0.5:/var/www/app
```
