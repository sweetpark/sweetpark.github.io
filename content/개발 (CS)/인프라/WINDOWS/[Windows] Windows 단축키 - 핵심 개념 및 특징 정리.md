# Windows 단축키

> [!NOTE]
> Windows 키보드 단축키와 실행창 명령어(MSC 콘솔, 제어판 CPL, 실행 명령어) 레퍼런스 모음.

## 💻 예시

### 키보드 단축키

- cmd 창 전체화면 : `Alt + Enter`
- 화면 분할 : `Windows + 화살표(← / →)`
- 내 PC 열기 : `Windows + E`
- 바탕화면 전환 : `Windows + D`
- 바탕화면 잠깐 보기 : `Windows + ,`
- 모든 창 최소화 : `Windows + M`
- 전체 작업 관리(작업 보기) : `Windows + Tab`
- 새 데스크톱 만들기 : `Ctrl + Windows + D`
- 데스크톱 이동 : `Ctrl + Windows + →` (or `←`)
- 데스크톱 삭제 : `Ctrl + Windows + F4`
- 현재 탭 닫기 : `Ctrl + W`
- 즐겨찾기 추가 : `Ctrl + D`
- 화면 비율 복구 : `Ctrl + 0`(숫자)
