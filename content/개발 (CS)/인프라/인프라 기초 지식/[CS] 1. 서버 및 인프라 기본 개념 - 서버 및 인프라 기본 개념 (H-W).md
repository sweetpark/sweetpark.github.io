# 서버 및 인프라 기본 개념 (H/W)

> [!NOTE]
> 서버 하드웨어 기초. KVM, 랙, RAID(0~10) 레벨별 특징, LVM 구성 요소, 서버실 운영 인프라(서버 팜·항온항습·UPS)를 정리.

## 📌 개념

### 서버 물리 기초

- **호스트명(Hostname)**: 서버를 식별·관리하기 위한 이름
- **KVM 스위치**: 하나의 키보드/모니터/마우스로 여러 대의 서버 본체를 선택적으로 제어하는 장치. 서버실 물리 서버 관리 시 필수
- **커널 기반 가상 머신(KVM, Kernel-based Virtual Machine)**: 리눅스 커널에 내장된 가상화 기술. 하이퍼바이저 역할을 커널이 직접 수행
- **랙(Rack)**: 서버를 장착하는 금속 프레임(BOX). 서버실의 서버 케이스들을 의미

### RAID

RAID는 여러 개의 물리 디스크를 하나의 논리 디스크처럼 사용하는 기술로, 성능 향상·데이터 안정성·가용성 확보가 목적이다.

| RAID | 방식 | 최소 디스크 | 특징 |
| --- | --- | --- | --- |
| RAID 0 | 스트라이핑 | 2 | 병렬 기록으로 성능↑, 1개 고장 시 전체 손실(안정성 없음) |
| Linear | 순차 채움 | 2 | 앞 디스크가 차면 다음에 저장. 성능 향상 없음, 구조 단순, 장애 시 손실 가능 |
| RAID 1 | 미러링 | 2 | 동일 데이터 복제. 공간 효율↓, 안정성↑, 1개 고장에도 안전 |
| RAID 2 | 스트라이프 + Hamming Code | - | 에러 검출·수정 가능. 부가 디스크 다수 필요, 현재 거의 미사용 |
| RAID 3 | 스트라이프 + Parity 전용 디스크 | - | Byte 단위. 연속 데이터 유리, Parity 디스크 병목 가능 |
| RAID 4 | Parity 전용 디스크 1개 | - | Block 단위, 실사용 N-1. Parity 디스크 부하 집중, 쓰기 성능 저하 |
| RAID 5 | Parity 분산 | 3 | N-1 용량 사용, 1개 장애 복구 가능, 2개 이상 장애 시 복구 불가 |
| RAID 6 | Parity 2개 | 4 | N-2 용량 사용, 2개 장애까지 복구, 신뢰성 높음, 쓰기 성능 저하 |
| RAID 10 | RAID 1 + RAID 0 | 4 | 성능 + 안정성 모두 확보, 비용·디스크 수 증가 |

- **스트라이핑**: 데이터를 여러 디스크에 나누어 병렬 기록
- **패리티(Parity)**: 데이터 손실 여부 확인용 정보. 장애 시 남은 데이터로 복구 가능
- **Hamming Code**: 패리티 기반 에러 검출 및 수정(오류 위치를 찾아 복구). 데이터 4개 디스크 기록 시 3개의 부가 디스크 필요

### LVM (Logical Volume Manager)

가상의 물리적 스토리지 공간을 생성하는 기술로, RAID 위에서도 동작 가능하다.

- **장점**: 유연한 용량 확장, 물리 디스크 초과 할당, 스토리지 풀 개념, 미러 볼륨 구성, 장치 이름 자유 지정
- **구성 요소**
    - **PV(Physical Volume)**: 실제 디스크를 LVM에서 사용 가능하게 만든 단위
    - **PE(Physical Extent)**: PV를 구성하는 고정 크기 블록(기본 4MB). PE와 LE 크기 동일
    - **VG(Volume Group)**: 여러 PV를 묶은 스토리지 풀. LV를 할당하는 단위
    - **LV(Logical Volume)**: 사용자가 실제로 사용하는 논리 디스크
- **LV 종류**
    1. 선형 LV — PE ↔ LE 1:1 매칭
    2. 스트라이프 LV — 데이터 분산 기록, 읽기/쓰기 병렬 처리
    3. 미러링 LV — 데이터 백업 목적

### 서버실 및 운영 인프라

- **서버 팜(Server Farm)**: 서버들이 사용하는 관리 네트워크. 랜선만 연결하면 어디서든 서버 관리 가능
- **항온·항습 시스템**: 서버실의 온도·습도 유지 시스템. 서버 안정성의 핵심
- **무중단 전력 시스템(UPS)**: 정전 시 서버를 보호하는 전원 장치(보조 배터리). 서버 안전 종료 또는 일정 시간 운영 가능

### 전체 요약 한 줄

- **RAID** → 디스크 성능/안정성
- **LVM** → 유연한 스토리지 관리
- **KVM/랙/UPS** → 서버 물리 운영
- **서버 팜 + 항온항습** → 안정적인 서버실 환경
