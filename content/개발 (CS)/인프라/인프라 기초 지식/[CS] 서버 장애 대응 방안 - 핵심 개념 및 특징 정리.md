# 서버 장애 대응 방안

> [!NOTE]
> 장애 유형(서버 / 서비스 / 네트워크)별 기본 점검 항목과 대응 방향 정리.

## 📌 개념

- **서버 문제**: CPU / MEM / DISK / 네트워크 인터페이스를 확인 후 최소 8시간 이내 처리
- **서비스 문제**: 어떤 서비스인지(web / was / erp / db / drm / dlp) 로그 분석 후 처리
- **네트워크 문제**: 방화벽 정책, 라우팅 정보, port 정보, ping 등 기본 체크 항목과 로그 정보 확인 후 처리
