# 스토리지(Storage) 운영 정리

> [!NOTE]
> EMC/IBM 스토리지 운영 정리. 관리 네트워크 IP 구성, 컨트롤러(SPA/SPB)·전원 이중화, LPAR/HMC, 부품 교체 절차, 용어 정리.

> [!CAUTION]
> 원문에 실제 현장(고객사) 스토리지 관리 IP와 로그인 계정·비밀번호가 평문으로 포함되어 있었다. 비밀번호와 현장별 IP는 보안상 `***MASKED***`로 마스킹했다. 실제 값은 사내 자산관리/비밀번호 관리 체계에서만 확인할 것.

## 📌 개념

### 1. 스토리지 관리 네트워크 (IP 구성)

EMC / IBM 관리 포트 IP 매핑(벤더 기본 직결 관리 IP):

- **EMC**: 오른쪽 포트 `128.221.1.250`, 왼쪽 포트 `128.221.1.251`
- **IBM**: 오른쪽 포트 `128.221.1.251`, 왼쪽 포트 `128.221.1.250`
- **관리 PC 직접 연결 시**: IP `128.221.1.249`, Subnet `255.255.255.248`

> [!NOTE]
> 스토리지 관리 포트에 직접 물려서 점검할 때 사용하는 고정 설정.

### 2. 컨트롤러 구조 (SPA / SPB)

- **EMC**: SPA = 오른쪽, SPB = 왼쪽
- **IBM**: SPA = 왼쪽, SPB = 오른쪽

> [!WARNING]
> 제조사별 SPA/SPB 위치가 반대 → 작업 전 반드시 확인.

### 3. 전원 구조 (Power)

- **Main Power**: 이중화 구성, SPA/SPB 기준으로 전원 분리. 장애 발생 시 즉시 영향 없음
- **Power Supply(Support)**: SPA 기준으로 구분, 보조 전원 성격. 고장 시 급박한 장애는 아님(교체는 필요)

### 4. Bus

- CPU와 주변장치(스토리지, NIC 등)를 연결하는 데이터 통로. 내부 데이터 이동의 핵심 경로

### 5. 논리 파티션 & HMC

- **Logical Partition(LPAR, 엘파)**: 물리 서버를 논리적으로 분할하여 여러 서버처럼 사용
- **HMC(Hardware Management Console)**: IBM 서버 관리 콘솔
    - LPAR 생성/관리, CPU·메모리 등 물리 스펙 할당, 하나의 서버를 여러 서버처럼 운용

### 6. 스토리지 부품 교체 절차

1. **유지보수 계약 여부 확인**: 고장 장비 제조사와 계약되어 있는지 확인
2. **부품 확인**: Serial Number, 부품명
3. **일정 조율 후 교체**: 담당자 사전 알림 → 현장 교체 진행

### 7. 관리 콘솔 로그인 정보

- **HMC**: ID `hscroot` / PW `***MASKED***`
- **ASMI(FSP 카드)**: ID `admin` / PW `***MASKED***`

### 8. 스토리지 로그인 정보 (현장별)

> [!CAUTION]
> 아래 현장별 IP·비밀번호는 실제 고객사 정보로, 보안상 마스킹함.

- **남원시청**
    - EMC Unity: IP `***MASKED***`, ID `admin`, PW `***MASKED***`
    - SAN Switch(IBM / EMC / Brocade): IP `***MASKED***`, ID `admin`, PW `***MASKED***`
- **전북도 교육청**
    - IBM 스토리지: IP `***MASKED***`, ID `superuser`, PW `***MASKED***`
    - 관리 PC 접속: IP `***MASKED***`, Subnet `255.255.255.0`
- **IBM 기본(Default) 관리 IP**
    - Cluster IP: `192.168.70.123 / 255.255.255.0`
    - Canister: `192.168.70.121 ~ 122`

### 9. 기본(Default) 계정

> [!CAUTION]
> 벤더 공장 초기 계정. 실제 운영 시 반드시 변경되어야 하므로 비밀번호는 마스킹함.

- **EMC**: ID `sysadmin` / PW `***MASKED***`
- **IBM**: ID `superuser` / PW `***MASKED***`

### 10. 용어 정리 (추가 학습 필요)

- **Canister(캐니스터)**: 스토리지 컨트롤러 모듈
- **Cluster**: 이중화/고가용성 구성 단위
- **FSP 카드**: 서버 하드웨어 상태 관리(전원/부팅/하드웨어 제어)
- **SPA / SPB**: 스토리지 컨트롤러 이중화 구성 요소

### 실무 요약 한 줄

- IP 혼동 주의 (EMC ↔ IBM 좌/우 반대)
- SPA/SPB 항상 기준 확인
- 전원은 이중화가 기본
- HMC = IBM 서버의 두뇌
- 부품 교체는 계약 → 부품 → 일정 순
