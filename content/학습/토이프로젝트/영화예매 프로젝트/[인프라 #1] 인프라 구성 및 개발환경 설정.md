# [인프라 #1] 인프라 구성 및 개발환경 설정

1. 인프라 구성  
2. 개발환경

## 인프라 구성

*   GCP 를 이용하여, DB 서버 및 웹서버 구축
*   Thymeleaf를 이용하여 View Page 구현 (Bootstrap 적용, jQuery를 이용하여 restAPI구현)
*   MariaDB를 사용하여, DB 구축 (JPA 사용 예정)

## 개발환경

*   JAVA 17 버전 사용
*   MariaDB 10.6 버전 이상 사용 **(10.6부터 호환되기에 11.4대신해서 10.6 사용)**
*   Spring boot 3.3.5 버전 사용 (thymeleaf 와 bootstrap은 버전에 맞춰 사용 예정)
*   intllij 사용
