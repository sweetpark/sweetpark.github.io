## 목록  만들기 ( <ol> ,  <ul> )

*   Ordered List
    *   <ol>  
        *   start : 순서의 시작 표시
        *   type : a , 1 .. 등  순서 표기를 위한 형식 지정
*   Unordered List
    *   <ul>
        *   순서가 없는 리스트

## 테이블 만들기

![](https://blog.kakaocdn.net/dna/ASqms/btsJ6GDzH4p/AAAAAAAAAAAAAAAAAAAAAI5jYlu9J6EoZGcVu1m3gEwnSzYcuBaYVLCFjNWFXGtr/img.png?credential=yqXZFxpELC7KVnFOS48ylbz2pIh7yKj8&expires=1790780399&allow_ip=&allow_referer=&signature=HEDyHiXyrfwewV1ImcoA9nbiEOc%3D)

*   <table>
    *   border : 표 둘레 두께 지정
*   <caption>
    *   표제목 지정
*   <thead> , <tbody>, <tfoot> : 시각적으로 html 문서에서 나타내기 위한 용도 ( 넣지 않아도 됨 )
    *   <thead> : 표의 첫번째 행 ( 표의 제목에 해당하는 부분)
    *   <tbody> : 표의 내용 부분
    *   <tfoot> : 표 마지막 요약 부분 (없는 경우도 많음)
*   <tr>
    *   행 (가로) 를 나타냄
*   <th>
    *   첫번째 행을 나타내는 부분 ( 행안에서 제목을 나타내는 부분)
*    <td>
    *   행(가로) 안에서 값을 나타내는 부분
