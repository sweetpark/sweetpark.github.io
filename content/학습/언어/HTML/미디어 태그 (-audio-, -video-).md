1. 오디오  
2. 비디오

## 오디오

![](https://blog.kakaocdn.net/dna/bUIwoo/btsJ7yMjK2I/AAAAAAAAAAAAAAAAAAAAAGtsUQo-AGrBQ38g_JrVJmp4jwhbKU91zuFwE3PE0uTi/img.png?credential=yqXZFxpELC7KVnFOS48ylbz2pIh7yKj8&expires=1790780399&allow_ip=&allow_referer=&signature=AWti823E8u%2FSX%2FONg96BhYvdH74%3D)

*   <audio>
    *   src : audio 파일 경로 입력
    *   autoplay loop : 자동 재생
    *   controls : 컨트롤 패널 표현
    *   <source> : 여러 형식의 audio 중에 웹브라우저에서 지원되는 태그 표현 ( 나머지 태그 무시됨 )

## 비디오

![](https://blog.kakaocdn.net/dna/bxu3QF/btsJ7cC19p7/AAAAAAAAAAAAAAAAAAAAAIUpZRcDBSeY4yI_DaXalSGOJaWLVnaeTOXjmURw8NUR/img.png?credential=yqXZFxpELC7KVnFOS48ylbz2pIh7yKj8&expires=1790780399&allow_ip=&allow_referer=&signature=dzHsNKVNCRncAMIi9cwQQ5CgZqc%3D)

*   <video>
    *   src : 비디오 파일 경로
    *   muted : 음소거
    *   autoplay : 자동 재생
    *   controls : 컨트롤 패널 이용
    *   <source> 지원하는 태그 표현 (나머지 태그 무시)
