## 공백 ( Entity Code ) 

*   일반적으로, 공백의 경우 여러개를 사용할 수 없다
*   그래서, 엔티티 코드 (특수문자 표현)를 사용
    *   & 로 시작 ;로 끝나는 표현 방식
