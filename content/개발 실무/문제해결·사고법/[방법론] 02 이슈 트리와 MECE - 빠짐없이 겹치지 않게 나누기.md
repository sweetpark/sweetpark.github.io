# 이슈 트리와 MECE - 빠짐없이 겹치지 않게 나누기

> [!NOTE] 한 줄 요약
> 큰 문제는 **하나의 기준**으로 나누면 **겹치지도, 빠지지도 않게** 쪼갤 수 있다.

## 먼저, 시험 범위 이야기

기말고사 공부 계획을 세운다고 해 볼게요. 이렇게 적으면 어떨까요?

- 국어
- 수학
- 시험 범위 많은 과목
- 어려운 과목

"수학"은 "시험 범위 많은 과목"과 **겹칠** 수 있고, 영어는 아예 **빠졌어요.** 이러면 계획이 엉망이 되겠죠?

## MECE가 뭐예요?

MECE(미시)는 영어 줄임말인데, 뜻은 간단해요.

| 글자 | 뜻 | 쉬운 말 |
|---|---|---|
| ME (Mutually Exclusive) | 서로 겹치지 않기 | 같은 걸 두 번 세지 않는다 |
| CE (Collectively Exhaustive) | 모으면 전체가 되기 | 빠진 게 없다 |

옷장 서랍 정리가 딱 이래요. 양말은 양말 서랍에만, 티셔츠는 티셔츠 서랍에만 넣으면 겹치지 않고, 옷 전부가 어딘가에 들어가면 빠지는 것도 없죠.

## 이슈 트리 그리는 법

이슈 트리는 문제를 **나뭇가지처럼** 쪼개 가는 그림이에요.

1. 맨 위에 풀 질문 하나를 쓴다.
2. **기준 하나**를 정해서 아래로 나눈다.
3. 더 쪼갤 수 있으면 같은 방법을 반복한다.
4. 마지막에 점검한다. 겹친 가지는? 빠진 가지는? ("그 밖의 경우" 칸을 만들어 비어 있는지 보면 편해요.)

## 예시: "게임 앱이 왜 실패할 수 있을까?"

```
앱이 실패할 수 있는 경우는?
├ 입력이 이상하다 : 빈칸 / 형식 틀림 / 너무 큰 값 / 중복
├ 내 상태가 이상하다 : 설정 없음 / 아직 준비 안 됨 / 동시에 접근
├ 상대가 이상하다 : 응답이 느림 / 에러 응답 / 연결이 끊김
└ 환경이 이상하다 : 재시작 / 시간이 어긋남
```

"누가 문제인가"라는 **기준 하나**로 나눴기 때문에 깔끔해요.

## 나누는 기준 예시

| 기준 | 나누는 예 |
|---|---|
| 흐름 | 정상 / 비정상 / 아슬아슬한 경계 |
| 시점 | 시작 전 / 하는 중 / 끝난 뒤 |
| 주체 | 나 / 상대방 / 환경 |
| 영향 | 코드 / 설정 / 저장된 데이터 / 기록(로그) |

## 조심할 점

- **한 층에서는 기준을 하나만** 쓰세요. "과목별"과 "난이도별"을 섞으면 처음 예시처럼 겹치고 빠집니다.
- 완벽한 MECE를 만드는 게 목표가 아니에요. **"빠진 데 없나?" 점검하는 도구**로 쓰면 충분해요.

## 정리

- 이슈 트리 = 문제를 나뭇가지처럼 쪼개는 그림
- MECE = 겹치지 않고(ME), 빠짐없이(CE)
- 기준은 **한 번에 하나!**
