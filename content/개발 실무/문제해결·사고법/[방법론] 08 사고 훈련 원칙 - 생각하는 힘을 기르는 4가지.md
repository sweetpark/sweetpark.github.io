# 사고 훈련 원칙 - 생각하는 힘을 기르는 4가지

> [!NOTE] 한 줄 요약
> 답을 외우는 게 아니라 **스스로 생각하는 힘**을 키우는 4가지 습관: 질문 예측하기, 질문의 의도 읽기, AI는 생각한 뒤에 쓰기, 큰 그림 보기.

## 원칙 1. 상대 입장에서 질문 미리 던져 보기

발표나 보고 전에 **"듣는 사람이 뭘 물어볼까?"** 를 예상해 보세요. 중요한 건 질문만 뽑고 끝내지 않고 **답까지 직접 써 보는 것**이에요. 생각한 느낌만 남으면 소용없거든요.

- 실제 발표 후에 **나온 질문과 내 예상을 비교**해요. 얼마나 맞았는지가 실력이 늘고 있다는 표시예요.
- 시험 직전에 예상 문제를 만들어 풀어 보는 것과 같아요.

## 원칙 2. 질문의 의도 읽기

똑같이 "이거 왜 이렇게 했어요?"라고 물어도 **속뜻**은 다를 수 있어요.

| 질문의 속뜻 | 이렇게 답하세요 |
|---|---|
| 근거가 있는지 보고 싶다 | 확인할 수 있는 증거를 보여 주기 |
| 영향이 어디까지인지 궁금하다 | 바뀌는 곳과 안 바뀌는 곳 말해 주기 |
| 내가 이해했는지 보고 싶다 | 내 말로 구조와 흐름을 설명하기 |
| 다른 방법도 생각했는지 궁금하다 | 후보와 탈락 이유 말하기 |

- 질문은 **공격이 아니라 피드백**이에요. 내 계획의 빈틈을 미리 알려 주는 선물이죠.
- 대답하기 전에 "이 질문은 뭘 확인하려는 걸까?"를 **한 번 생각**해요.

## 원칙 3. AI는 "내가 먼저 생각한 뒤에" 쓰기

| 구분 | 내용 |
|---|---|
| 내가 먼저 할 것 | 문제 정의, 내 가설과 초안, 이유 한 줄 |
| AI에게 물을 것 | 모르는 개념·문법, 구현 방법, **내 생각의 허점 찾기** |
| 피할 것 | 내 생각 없이 정답부터 받기 |

수학 문제를 풀 때 바로 해설지부터 보면 그때는 편하지만 실력이 안 늘죠? AI도 같아요. 가장 좋은 방법은 **내 답을 먼저 쓰고, AI에게 "틀린 곳이 있는지 찾아 줘"** 하고 부탁하는 거예요.

- AI의 답을 받은 뒤에도 **"왜 이 답이 맞지?"** 를 내 말로 한 줄 써 보세요.
- 확인하지 못했다면 "추측"이라고 표시해 두세요.

## 원칙 4. 큰 그림 → 확대 → 다시 큰 그림

지도를 볼 때 처음엔 전체를 보고, 목적지 근처를 확대하고, 다시 줄여서 길이 맞는지 확인하죠. 일도 똑같아요.

1. **멀리서 보기**: 전체 구조와 흐름은 어떻지?
2. **가까이서 보기**: 내가 바꾸는 부분만 확대해서 확인
3. **다시 멀리서 보기**: 큰 흐름에 문제가 없는지, 빠진 곳은 없는지 확인

점검 질문: "이 변경은 어떤 길, 데이터, 설정, 기록에 닿을까? **닿지 않는 건 왜 안 닿을까?**"

큰 그림만 알고 세부를 모르면 위험하고, 세부만 알고 큰 그림을 모르면 길을 잃어요. 둘 다 필요해요.

## 4가지를 한눈에

| 원칙 | 한마디 |
|---|---|
| 1. 질문 예측 | 물어볼 것을 먼저 상상하고 답까지 써 보기 |
| 2. 의도 읽기 | 질문은 공격이 아닌 피드백 |
| 3. AI 활용 | 내가 먼저, 그다음 AI |
| 4. 큰 그림 | 멀리 → 가까이 → 다시 멀리 |
