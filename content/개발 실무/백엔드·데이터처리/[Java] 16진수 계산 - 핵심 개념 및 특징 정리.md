# 16진수 계산

> [!NOTE]
> 비트·바이트와 16진수의 대응 관계, 그리고 자바에서 비트 OR 연산으로 플래그를 합치는 예시.
> 원문을 AI가 검토·보강함(사실 확인 권장).

## 📌 개념

- **바이트 단위**: 1 Byte = 8 Bit
- **2진수**: `0000` = 4 Bit
- **16진수**: `0xF` = 4 Bit, `0xFF` = 8 Bit (= 1 Byte)
- 16진수 한 자리는 2진수 4비트(nibble)에 정확히 대응하므로 비트 마스크·플래그 표현에 자주 쓰인다.

## 💻 예시

```java
byte b = 0x00;
b |= 0x10; // 0001 0000 == 16
b |= 0x01; // 0000 0001 == 1
b |= 0x16; // 0001 0110 == 22
// b == 23  (0x10 | 0x01 | 0x16 == 0x17)
```

- `|=`(비트 OR)로 여러 플래그를 하나의 byte에 누적한다.
- 계산: `0x10 | 0x01 | 0x16 = 0001 0111 = 0x17 = 23`.
