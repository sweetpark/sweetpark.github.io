# 백준 로컬 코테 템플릿

> [!NOTE]
> 개요
> 백준 문제를 로컬에서 풀 때 쓰는 프로젝트 구성 메모: 유틸(시간·메모리 제한, 입력 처리)은 테스트 코드 쪽에, 실제 제출용 파일에는 `main` + `solution`만 둔다.

## 📌 개념
- **유틸 만들기**
    - 시간 제한
    - 메모리 제한
    - 입력값 받기 (args 처리)
    - 해당 유틸은 테스트 코드 파일에 적용
        - 메인 + solution 호출 (args 입력 이용)
- **메인 들어간 파일**
    - 메인 + solution만 기입
