# [실기] (PART 4) 통합구현

> [!NOTE]
> 정보처리기사 실기 PART 4 — 직접/간접 연계 기술 등 시스템 통합 구현 핵심 정리.

## 📌 개념

- 주요연계기술
    - 직접연계
        - DB링크 : 송신시스템에서 해당 DB링크를 직접 참조
        - DB연결 : DB커넥션 풀을 이용하여 연결
        - API : DB에서 데이터를 읽어서 제공하는 애플리케이션 프로그래밍 인터페이스 프로그램
        - JDBC : 수신 시스템의 프로그램에서 JDBC 드라이버를 이용하여 송신 DB와 연결
        - 하이퍼링크 : 다른 페이지로 이동
    - 간접연계
        - EAI : 기업에서 운영되는 서로다른 애플리케이션 연결
        - ESB : 웹서비스가 설명된 시스템간 연계 (WSDL : 웹서비스 상세정보가 기술된 XML 형식 구현, SOAP : HTTP, HTTPS 등을 사용하여 XML 기반의 메시지를 교환
        - Socket : 포트를 할당하여 클라이언트 요청을 연결하여 통신
- EAI 구성 요소
    - EAI 플랫폼 : 데이터 전송을 위한 메시지 큐와 트랜잭션 미들웨어 기능 수행, 이기종 시스템 간 애플리케이션 상호 운영
    - 어댑터 : EAI 핵심장치, 데이터 입출력 도구
    - 브로커 : 데이터 포맷과 코드 변환
    - 메시지 큐 : 비동기 메시지 송수신
    - 비즈니스 워크플로우 : 미리정의된 기업의 workflow에 따라 업무 처리
- EAI 구축 유형
    - 포인트 투 포인트 : 1:1 단순 통합
    - 허브 앤 스포크 : 허브시스템 도입
    - 메시지 버스 : 미들웨어(버스)를 두어 통합
    - 하이브리드 : 허브앤스포크 (그룹내) + 메시지버스 (그룹외)
- ESB
    - 각 프로토콜이 호환할 수 있도록 통합을 느슨한 결합방식 지원
    - 버스 방식

---

- 웹서비스 방식
    - HTTP : GET, POST, PUT 방식 사용
    - 하이퍼텍스트 : 문장이나 단어 들이 링크
    - HTML : 인터넷웹(WWW)문서를 표현하는 마크업언어
- IPC
    - 프로세스간 데이터 통신 기술
- IPC 주요 기법
    - 메시지큐 : 패킷 또는 메시지 단위로 프로세스 통신
    - 공유메모리 : 다른 프로세스와 공유
    - 소켓 : 클라이언트-서버 통신
    - 세마포어 : 프로세스 동기를 맞춤
