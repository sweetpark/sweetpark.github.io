# [실기] (PART 8) 서버프로그램 구현

> [!NOTE]
> 정보처리기사 실기 PART 8 — 개발 환경(운영체제·미들웨어)과 서버 프로그램 구현 관련 개념 정리.

## 📌 개념

- 소프트웨어 개발 환경
    - 운영체제
    - 미들웨어 : 컴퓨터간 연결 (자바기반환경에서 JVM을 설치하여 컨테이너로의 기능을 주로 이용)
    - DBMS : 데이터베이스를 관리해주는 소프트웨어
- 형상관리 절차
    - 형상 식별 : 관리번호를 이용하여 추적
    - 형상 통제 : 형상 통제 위원회 운영
    - 형상 감사 : 베이스라인의 무결성 평가
    - 형상 기록 : 변경관리 기록
- 소프트웨어 형상관리 도구 유형
    - 공유폴더 방식 : RCS , SCCS
    - 클라이언트/서버 방식 : CVS, SVN
    - 분산 저장소 방식 : GIT
- 소프트웨어 형상 관리 도구별 특징
    - CVS : 서버-클라이언트, 다수의 인원이 동시에 운영체제 접근
    - SVN : 하나의 서버에서 관리
    - RCS : 소스파일 수정을 한사람만 (파일잠금방식)
    - Bitkeeper : 중앙통제방식 , 대규모프로젝트
    - Git : 분산형 버전관리 시스템
    - Clear Case : 복수서버, 복수 클라리언트 구조

---

- 재사용 종류
    - 재공학 : 기존 기능 개선
    - 재개발 : 기존 것을 이용하여 새로운 시스템개발
- 응집도
    - 우연적 응집도 : 각 구성요소 연관 x
    - 논리적 응집도 : 유사한 성격을 가짐
    - 시간적 응집도 : 특정 시간에 처리
    - 절차적 응집도 : 순차적으로 수행
    - 통신적 응집도 : 동일한 입력과 출력을 사용하여 다른 기능 수행
    - 순차적 응집도 : 다른 모듈의 출력값을 다른 활동이 사용할 경우
    - 기능적 응집도 : 모듈 내부의 모든 기능이 단일한 목적 수행
- 결합도
    - 내용 결합도 : 다른 모듈의 변수나 기능을 사용
    - 공통 결합도 : 전역변수 참조
    - 외부 결합도 : 외부에서 선언한 변수를 다른 모듈에서 참조, (포맷, 프로토콜, 인터페이스를 공유)
    - 제어 결합도 : 다른 모듈의 내부논리조직을 제어 (권리 전도 현상 발생)
    - 스탬프 결합도 : 인터페이스로 배열이나 객체, 구조 등이 전달
    - 자료 결합도 : 인터페이스로 전달되는 파라미터를 통해서만 모듈간의 상호작용
- 팬인 팬아웃
- 공통 모듈 테스트 종류
    - jUnit : 자바
    - CppUnit : C++
    - HttpUnit : 웹 브라우저 없이 웹 테스트

---

- 배치 프로그램 유형
    - 이벤트 매치 : 조건 충족시 실행
    - 온디맨드 매치 : 명시적 요구
    - 정기 배치 : 정해진 시점에 실행
- 배치 스켈러의 종류
    - 스프링 배치 : 스프링 프레임워크의 3대요소를 모두 사용
    - 쿼츠 스케줄러 : 작업과 스케줄을 정의하는 트리거를 분리 (유연성 제공)
- Cron 표현식
    - 초, 분, 시, 일, 월, 요일, 연도
