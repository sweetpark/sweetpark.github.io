# 2026-10-24 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The controller state SHALL persist across pod restarts to maintain session continuity.

**A.** 뜻: Pod 재시작 후에도 컨트롤러 상태가 유지되어야 한다.

구문 설명: 'SHALL persist across [event]'는 재시작, 재부팅 등의 특정 이벤트가 발생하더라도 상태나 데이터가 유실되지 않고 계속 유지되어야 함을 규정하는 필수(Mandatory) 요구사항 표현입니다.

관련 비교: 'SHALL'은 필수 구현 항목이며, 만약 선택 사항이라면 'MAY persist across'로 표기합니다.

**Q.** The allocation of internal IP addresses SHALL be determined based on the network topology configuration.

**A.** 뜻: 내부 IP 주소 할당은 네트워크 토폴로지 설정에 기반하여 결정되어야 한다.

구문 설명: 'SHALL be determined based on [condition/data]'는 동작이나 값의 결정 기준이 무엇인지 명확히 규정할 때 사용하는 스펙 문서 표준 구문입니다.

관련 비교: 결정 권한이 시스템 구현 방식에 위임된 경우에는 'is implementation-defined' 구문을 사용합니다.

**Q.** The current resource status MAY be queried on demand by the control plane.

**A.** 뜻: 리소스의 현재 상태는 컨트롤 플레인에 의해 필요시(요청에 따라) 조회될 수 있다.

구문 설명: 'MAY'는 선택적 기능(Optional)을 나타내며, 'on demand'는 주기적 전송이 아닌 필요할 때 즉시 요청하여 수행하는 동작 방식을 뜻합니다.

**Q.** Any incoming payload lacking a valid cryptographic signature SHALL be considered invalid.

**A.** 뜻: 유효한 암호화 서명이 없는 모든 수신 페이로드는 무효한 것으로 간주되어야 한다.

구문 설명: 'SHALL be considered [adjective/noun]'은 특정 조건을 충족하지 않거나 충족하는 대상에 대한 법적/규격상 상태를 정의할 때 쓰입니다.

관련 비교: 'SHALL be treated as'와 유사하게 시스템이 해당 데이터를 어떻게 간주하고 처리해야 하는지 강제할 때 쓰입니다.

## GitHub 소통 문구

**Q.** PR 작성 시 "이 PR은 기능 변경 없이 단순 리팩토링 및 코드 정리만 포함합니다"라고 알려주고 싶을 때 뭐라고 말할까요?

**A.** 영어 표현: "This PR contains refactoring and code cleanup only, with no functional changes."

유사 표현:
- "No breaking or functional changes introduced; strictly code polish."
- "Refactoring only—behavior should remain unchanged."

사용 상황: 리뷰어가 버그나 스펙 변경 가능성에 대한 부담 없이 구조 위주로 빠르게 리뷰할 수 있도록 PR 묘사란에 적어둘 때 사용합니다.

**Q.** 코드 리뷰 중 "이 변경 사항이 기존 유닛 테스트로 커버되고 있나요, 아니면 새 테스트를 추가해야 할까요?"라고 질문하고 싶을 때 뭐라고 말할까요?

**A.** 영어 표현: "Is this scenario covered by existing unit tests, or should we add a new test case?"

유사 표현:
- "Does existing test coverage account for this edge case?"
- "Should we include a dedicated test case for this logic?"

사용 상황: 수정된 로직이나 에지 케이스에 대한 테스트 코드가 이미 존재하는지, 혹은 추가 작성이 필요한지 리뷰어/작성자에게 조심스럽게 확인할 때 사용합니다.

## 생활영어

뉘앙스 설명: 'nail it'은 힘든 일, 발표, 시험, 과제 등을 아주 정확하고 완벽하게 성공시켰을 때 격려와 찬사로 자주 쓰는 친근하고 역동적인 표현입니다. 비슷하게 'You killed it!'도 자주 쓰입니다.

## 단어

**Q.** preemption

**A.** 뜻: 우선점유, (더 높은 우선순위 작업에 의한) 리소스 강제 회수/선점

예문: "Kubernetes uses pod preemption to evict lower-priority pods when cluster resources are insufficient."
(쿠버네티스는 클러스터 자원이 부족할 때 낮은 우선순위 파드를 강제 퇴출시키기 위해 파드 선점 기법을 사용합니다.)
