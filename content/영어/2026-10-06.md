# 2026-10-06 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The controller shall validate the resource status prior to initiating the update procedure.

**A.** 의미: 컨트롤러는 업데이트 절차를 시작하기 전에 리소스 상태를 검증해야 한다.

구문 패턴: `prior to + [동명사/명사]`
- '~하기 전에'라는 뜻으로, 기술 문서(3GPP 스펙, K8s 공식 문서 등)에서 특정 동작을 수행하기 위한 선행 조건을 규정할 때 'before' 대신 사용하는 격식 있는 기술 문서 표현입니다.

**Q.** A pod eviction process shall be initiated by the node controller when memory pressure exceeds the defined threshold.

**A.** 의미: 메모리 압박이 정의된 임계값을 초과할 때 노드 컨트롤러에 의해 파드 축출 프로세스가 시작되어야 한다.

구문 패턴: `shall be initiated by + [주체/조건]`
- 특정 동작/프로세스가 어느 주체나 어떤 조건에 의해 개시되는지를 수동태 구조로 명확히 명시하는 표준 스펙 표현입니다.
- `shall`은 RFC 2119 규격상 필수/강제 규정(Mandatory)을 의미합니다.

**Q.** The maximum number of retries shall not exceed the limit defined in the configuration specification.

**A.** 의미: 최대 재시도 횟수는 설정 명세서에 정의된 제한을 초과해서는 안 된다.

구문 패턴: `shall not exceed + [수치/임계값]`
- 시스템 한계, 할당량(Quota), 재시도 횟수 등의 상한선을 절대적으로 제한할 때 쓰이는 문구입니다.
- `SHALL NOT`은 RFC 2119 규격에서 절대 금지(Absolute Prohibition)를 뜻합니다.

**Q.** The ingress controller shall notify the backend service of any changes in routing rules.

**A.** 의미: 인그레스 컨트롤러는 라우팅 규칙의 변경 사항을 백엔드 서비스에 통지해야 한다.

구문 패턴: `shall notify [대상] of [내용]`
- '[대상]에게 [내용]을 통지해야 한다'는 구문으로, 시스템 컴포넌트 간 상태 변경 알림이나 이벤트 전달 의무를 규정할 때 빈번하게 사용됩니다.

## GitHub 소통 문구

**Q.** 코드 리뷰 시 단순 오타(typo)를 발견했을 때 부드럽게 지적하며 수정을 요청하고 싶다면?

**A.** 영어 표현: "Looks like a typo here: `receve` -> `receive`"

유사 표현:
- "I think this might be a typo."
- "Nit: typo in the function name."

사용 상황: 변수명, 주석, 로그 메시지 등에서 오탈자를 발견했을 때 비판적이지 않고 가볍게 피드백을 남길 때 주로 사용합니다.

**Q.** PR 변경량이 많아서 꼼꼼히 리뷰하는 데 시간이 조금 걸릴 것 같다고 작성자에게 미리 양해를 구하고 싶다면?

**A.** 영어 표현: "This is a sizable PR, so it might take me a bit longer to review thoroughly."

유사 표현:
- "Taking a look now! Given the size of the changes, I'll need some time to digest this."
- "Leaving a quick note that I'm reviewing this—will leave detailed comments soon."

사용 상황: 대규모 PR이나 복잡한 리팩토링 PR을 할당받았을 때, 작성자가 답변을 무작정 기다리지 않도록 검토 소요 시간을 사전에 안내할 때 사용합니다.

## 생활영어

**Q.** 동료와 대화나 미팅 중에 '아, 방금 내가 무슨 말을 하려고 했는지 깜빡했다!'라고 말하고 싶을 때

**A.** 영어 표현: "Sorry, I completely lost my train of thought."

뉘앙스 설명:
- 'lose one's train of thought'는 머릿속에 이어지던 생각의 흐름(train of thought)을 순간적으로 놓치거나 잊어버렸을 때 쓰는 매우 자연스러운 일상 및 업무 표현입니다.

## 단어

**Q.** reconcile

**A.** 뜻: (상태/데이터를) 조정하다, 조화시키다, (원하는 상태와 실제 상태를) 일치시키다

예문: "The controller periodically runs a loop to reconcile the actual cluster state with the desired state defined in the spec."
(컨트롤러는 주기적으로 루프를 실행하여 실제 클러스터 상태를 명세에 정의된 원하는 상태와 일치시킨다.)
