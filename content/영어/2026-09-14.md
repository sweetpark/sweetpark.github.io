# 2026-09-14 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The Pod status MUST be updated in accordance with the conditions defined in section 3.2.

**A.** 뜻: Pod 상태는 3.2절에 정의된 조건에 따라 업데이트되어야 한다(MUST).

[구문 패턴 설명]
'in accordance with ~': '~에 따라서', '~를 준수하여'. 스펙 문서나 API 규격에서 특정 절차/규격을 엄격히 따를 때 자주 쓰입니다.

[MUST vs SHOULD]
MUST는 필수(Mandatory) 사양으로, 준수하지 않으면 호환되지 않거나 오류로 간주됩니다.

**Q.** The controller SHOULD retry the operation upon encountering a transient error.

**A.** 뜻: 컨트롤러는 일시적 에러를 마주했을 때 해당 작업을 재시도해야 한다(권장).

[구문 패턴 설명]
'upon + -ing / Noun': '~하자마자', '~했을 때'. 특정 이벤트 발생 직후의 동작을 정의할 때 사용됩니다.

[SHOULD 의미]
SHOULD는 권고사항(Recommended)으로, 정당한 이유가 있다면 따르지 않을 수 있으나 강력히 권장됨을 의미합니다.

**Q.** The SMF MAY release the PDU session for the purpose of resource optimization.

**A.** 뜻: SMF는 자원 최적화를 목적으로 PDU 세션을 해제할 수 있다(선택).

[구문 패턴 설명]
'for the purpose of ~ing/Noun': '~를 목적으로'. 동작의 기술적 의도나 배경을 설명할 때 규격서에서 빈번하게 등장합니다.

[MAY 의미]
MAY는 선택사항(Optional)으로, 구현체(Implementation)에서 이 기능을 지원할 수도 있고 하지 않을 수도 있음을 나타냅니다.

## GitHub 소통 문구

**Q.** 이럴 때 뭐라고 말하지?
'이 부분은 동기식 대신 비동기로 처리하는 게 어떨까요?'처럼 더 나은 구현 방향을 부드럽게 제안하고 싶을 때

**A.** 영어 표현:
How about processing this asynchronously instead of synchronously?

유사 표현:
- Would it make sense to process this asynchronously?
- What do you think about making this asynchronous?

사용 상황:
상대방의 코드 방식을 직접 비판하지 않고, 더 권장되는 패턴이나 대안을 조심스럽고 협력적으로 제안할 때 PR 리뷰에서 유용합니다.

**Q.** 이럴 때 뭐라고 말하지?
'리뷰하기가 조금 커서 그런데, 혹시 이 PR을 두 개로 나눠서 올려주실 수 있나요?'라고 요청하고 싶을 때

**A.** 영어 표현:
Could we split this PR into smaller chunks to make it easier to review?

유사 표현:
- Would you mind breaking this PR down into separate PRs?
- This PR is a bit large. Could we divide it into two?

사용 상황:
PR의 변경 사항(diff)이 너무 커서 코드 변경점을 한눈에 파악하기 힘들 때, 작성자에게 분리를 친절하게 요청하는 상황입니다.

## 생활영어

**Q.** 일상 대화 상황:
상대방의 설명이나 이유를 듣고 '아, 그렇게 들으니 납득이 되네 / 일리가 있네'라고 동의할 때 뭐라고 할까요?

**A.** 영어 표현:
That makes sense.

뉘앙스 설명:
상대방의 논리나 이유를 이해했고, 그것이 합리적이라고 느낄 때 가장 자연스럽게 쓰는 추임새입니다. 반대로 잘 이해가 안 가거나 납득이 안 될 때는 'That doesn't make sense.'라고 응답할 수 있습니다.

(기술/소프트웨어에서) 더 이상 사용을 권장하지 않다, 폐기 예정으로 지정하다.

## 스크랩(실전 표현)

**Q.** The AMF **shall** reject the registration request if the UE's requested NSSAI is not permitted.

**A.** 뜻:
UE가 요청한 NSSAI가 허용되지 않는 경우, AMF는 등록 요청을 거절해야 한다(필수).

표현 분석:
- **shall + 동사원형**: 3GPP 및 표준 스펙 문서에서 '의무/필수 규격(Mandatory requirement)'을 나타냅니다. 구현체는 이를 반드시 준수해야 합니다.
- **registration request**: UE가 네트워크에 접속하기 위해 보낼 때 사용하는 등록 요청 절차 메시지입니다.
- **permitted**: '허용된, 승인된'. NSSAI(네트워크 슬라이스 식별자)가 해당 서브스크립션이나 지역에서 유효하지 않은 상황을 의미합니다.
