# 2026-11-03 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The timeout duration SHALL be expressed in units of milliseconds.

**A.** 뜻: 타임아웃 기간은 밀리초 단위로 표시되어야 한다 (SHALL).

구문 패턴 설명:
- `SHALL be expressed in units of [unit]`는 스펙 문서에서 시간, 용량, 수치 파라미터의 단위를 엄격하게 규정할 때 사용하는 전형적인 구문입니다.
- 스펙 영어에서 `SHALL`은 준수해야 하는 필수(Mandatory) 요구사항을 나타내며, 개발 시 반드시 지정된 단위(예: ms, bytes)로 구현해야 함을 명시합니다.

**Q.** Configuration changes SHALL NOT take effect until the pod is restarted.

**A.** 뜻: 설정 변경 사항은 파드가 재시작될 때까지 적용되지 않는다 (SHALL NOT).

구문 패턴 설명:
- `SHALL NOT take effect until [event]`는 특정 이벤트(재시작, 특정 상태 도달 등)가 발생하기 전까지는 변경 사항이 활성화되지 않는다는 동작 조건과 시점을 명확히 정의할 때 쓰입니다.
- `take effect`(효력을 발휘하다)와 `until` 조건문이 결합하여 지연 적용(deferred application) 특성을 서술합니다.

**Q.** Audit logs SHALL be retained for a duration of 30 days unless a longer period is specified.

**A.** 뜻: 더 긴 기간이 지정되지 않는 한, 감사 로그는 30일 동안 유지되어야 한다 (SHALL).

구문 패턴 설명:
- `SHALL be retained for a duration of [time]`은 데이터 보존 기간(retention period)을 서술할 때 표준 기술 문서에서 빈번히 사용하는 표현입니다.
- 뒤이어 결합된 `unless [condition]` 구문은 기본 보존 기간에 대한 예외 조건(상위 설정이나 별도 정책)을 기술합니다.

**Q.** The authentication token MUST be provided in the form of a Bearer token in the request header.

**A.** 뜻: 인증 토큰은 요청 헤더에 Bearer 토큰 형태로 제공되어야 한다 (MUST).

구문 패턴 설명:
- `MUST be provided in the form of [format]`은 입력 데이터나 파라미터가 따라야 하는 구체적인 형식/포맷을 강제할 때 쓰입니다.
- RFC 2119 기준 `MUST`는 `SHALL`과 동일하게 절대적인 필수 요구사항(Absolute Requirement)을 나타냅니다.

## GitHub 소통 문구

**Q.** PR 리뷰할 때 '이 복잡한 로직을 별도 헬퍼 함수로 추출하는 건 어떨까요?'라고 부드럽게 제안하고 싶을 때

**A.** 영어 표현: Would it be possible to extract this logic into a helper function?

유사 표현:
- How about extracting this logic into a separate helper method?
- We could consider extracting this to improve readability.

사용 상황: 코드가 길어지거나 가독성을 높이기 위해 함수 분리(refactoring)를 제안할 때, 지시조가 아닌 정중한 제안의 톤으로 사용합니다.

**Q.** 이슈 코멘트에서 버그 보고자에게 '문제를 재현할 수 있는 최소한의 예시 코드를 공유해 주실 수 있나요?'라고 요청할 때

**A.** 영어 표현: Could you provide a minimal reproducible example?

유사 표현:
- Do you mind sharing a minimal code snippet to reproduce this?
- A minimal reproducible example (MRE) would be super helpful for debugging this.

사용 상황: 오픈소스 이슈나 버그 리포트에 첨부된 설명만으로 재현이 어려울 때, 개발자가 원인을 파악할 수 있도록 최소한의 코드/환경을 요청할 때 쓰는 대표적인 문구입니다.

## 생활영어

**Q.** 상대방의 설명을 듣다가 '아, 뭔지 딱 알겠어요! / 상황 파악이 됐어요!'라고 신나게 호응할 때

**A.** 영어 표현: Ah, I get the picture now!

뉘앙스 설명: 상대방이 전반적인 전말이나 복잡한 상황을 설명해 준 뒤, 전체적인 그림(상황)이 머릿속에 명확히 들어왔을 때 쓰는 표현입니다. 단순히 '알겠다(I see / I understand)'보다 훨씬 생생하게 파악했음을 나타냅니다.

## 단어

**Q.** cardinality

**A.** 뜻: (데이터베이스/프로메테우스 메트릭) 카디널리티, 고유한 값의 개수 (수량성)

예문: High cardinality metrics in Prometheus can significantly increase memory usage and slow down queries.
