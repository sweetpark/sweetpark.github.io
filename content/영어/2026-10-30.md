# 2026-10-30 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The Pod status SHALL be reported as Pending if one or more containers have not been initialized.

**A.** 뜻: 하나 이상의 컨테이너가 초기화되지 않은 경우 Pod 상태는 Pending으로 보고되어야 한다.

구문 패턴: SHALL be reported as [State] if [Condition] (특정 조건 충족 시 시스템/객체의 상태 정의)
- SHALL은 규격 문서에서 필수(Mandatory) 사양을 나타냅니다. 해당 조건이 참일 때 시스템이 반드시 이 상태를 반환/표시해야 함을 규정합니다.

**Q.** The term 'node' MAY be used interchangeably with 'worker' in the context of cluster operations.

**A.** 뜻: 클러스터 작업 맥락에서 'node'라는 용어는 'worker'와 혼용되어 사용될 수 있다.

구문 패턴: MAY be used interchangeably with [Term] (두 용어나 파라미터가 호환 가능하거나 동일하게 해석될 수 있음을 규정)
- MAY는 선택 사항(Optional) 또는 허용성을 의미합니다. 스펙 문서에서 동의어 관계나 호환 가능한 표현을 유연하게 허용할 때 자주 쓰입니다.

**Q.** If an integer is supplied where a string is expected, the value SHALL be implicitly converted to a string.

**A.** 뜻: 문자열이 예상되는 위치에 정수가 입력되면 해당 값은 암묵적으로 문자열로 변환되어야 한다.

구문 패턴: SHALL be implicitly converted to [Type] (명시적 타입 변환 동작 규정)
- implicitly는 '암묵적으로/자동으로'라는 의미로, 명시적 지정(explicitly) 없이 내부 로직에 따라 타입이 자동 전환되어야 하는 규격을 명시합니다.

**Q.** Messages sent to the queue SHALL be guaranteed to be delivered at least once.

**A.** 뜻: 큐로 전송된 메시지는 적어도 한 번 이상 전달됨이 보장되어야 한다.

구문 패턴: SHALL be guaranteed to be [Verb-ed] (시스템의 품질 보장/SLA 규정)
- 분산 시스템 및 통신 스펙에서 At-least-once, Exactly-once 등의 전송 보장 메커니즘을 명확히 규정할 때 핵심적으로 사용하는 패턴입니다.

## GitHub 소통 문구

**Q.** PR에 변경사항이 너무 많아 파악이 어려울 때, '어떤 부분을 집중해서 봐야 할지 가이드해주실 수 있나요?'라고 예의 바르게 요청하고 싶을 때

**A.** 영어 표현: Could you point me to the main areas I should focus on in this review?

유사 표현:
- Where should I start reviewing first?
- Could you give me a quick high-level overview of where to look?

사용 상황: 변경된 코드의 분량이 많아서 어디서부터 리뷰를 시작해야 할지 막막할 때, 작성자에게 집중 검토 포인트를 가이드해 달라고 요청하는 매너 있는 문구입니다.

**Q.** 수정한 코드가 테스트 환경에서 잘 동작함을 확인한 후, 검증 차원에서 '로컬 환경에서 철저히 테스트했고 문제없이 잘 작동합니다'라고 리뷰어에게 공유하고 싶을 때

**A.** 영어 표현: I tested this thoroughly in my local environment and everything looks solid.

유사 표현:
- I verified this change locally and confirmed it works as expected.
- Ran the full test suite locally and all tests passed without issue.

사용 상황: PR 본문이나 리뷰 답글에서 변경 사항을 직접 신중하게 검증했음을 알려 리뷰어에게 신뢰감을 전달할 때 쓰입니다.

## 생활영어

**Q.** 동료와 스몰 토크 중 '요즘 일정이 너무 빽빽해서/정신없이 바빠서 여유가 없다'라고 유연하게 표현하고 싶을 때

**A.** 영어 표현: My schedule has been pretty jammed lately.

유사 표현:
- Things have been super hectic on my end.
- My calendar is completely packed this week.

뉘앙스 설명: 'jammed'는 교통 정체처럼 일정이나 스케줄표가 꽉 막혀 여유가 없음을 비유적으로 나타냅니다. 단순히 'busy'라고 말하는 것보다 스케줄이 밀도 있게 차 있다는 느낌을 생생하게 전달합니다.

## 단어

**Q.** canonical

**A.** 뜻: (전산/개발) 표준적인, 정규화된, 대표적인 (가장 기본적이고 표준화된 상태나 형식을 의미함)

예문: We need to convert incoming JSON logs into a canonical data structure before saving them to the database.
(DB에 저장하기 전에 들어오는 JSON 로그를 표준화된 데이터 구조로 변환해야 합니다.)
