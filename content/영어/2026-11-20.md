# 2026-11-20 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** Spec expression: Objects of this type SHALL NOT be modified in-place once persisted.

**A.** 뜻: 이 유형의 객체는 한번 영구 저장(persisted)되면 제자리에서 수정(in-place modification)될 수 없다(SHALL NOT).

구문 패턴: `SHALL NOT be modified in-place` (제자리/현 위치 수정 금지)
- SHALL NOT: 강한 금지(Prohibition). 스펙상 절대로 허용되지 않음을 명시합니다.

**Q.** Spec expression: Resource limits MAY be specified as a percentage of the total node capacity.

**A.** 뜻: 리소스 제한은 전체 노드 용량의 백분율로 지정될 수 있다(MAY).

구문 패턴: `MAY be specified as a percentage of` (~의 백분율/비율로 지정될 수 있음)
- MAY: 선택 권한(Permission/Optional). 구현체나 사용자가 선택적으로 적용할 수 있음을 나타냅니다.

**Q.** Spec expression: If omitted, the parameter SHALL be assigned a value of zero.

**A.** 뜻: 생략된 경우, 해당 파라미터에는 0이라는 값이 할당되어야 한다(SHALL).

구문 패턴: `SHALL be assigned a value of` (~라는 값이 할당되어야 함)
- SHALL: 의무 규정(Mandatory Requirement). 해당 규칙이 강제됨을 의미합니다.

**Q.** Spec expression: Blocking I/O operations SHOULD be avoided when possible to prevent thread starvation.

**A.** 뜻: 스레드 고갈을 방지하기 위해 가능한 경우 블로킹 I/O 작업은 지양되어야 한다(SHOULD).

구문 패턴: `SHOULD be avoided when possible` (가능한 경우 ~를 지양/피해야 함)
- SHOULD: 권장 사항(Recommendation). 타당한 이유가 없는 한 지켜야 함을 의미합니다.
