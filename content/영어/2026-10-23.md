# 2026-10-23 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** Each Network Function instance shall be assigned a unique identifier upon initialization.

**A.** 뜻: 각 네트워크 기능 인스턴스는 초기화 시 고유 식별자를 할당받아야 한다.

구문 패턴: 'shall be assigned [something]' (~이 할당되어야 한다)
- 스펙 문서에서 특정 엔티티나 리소스에 유일한 값/식별자를 필수적으로 부여해야 함을 명시하는 강제성(SHALL) 구문입니다.

**Q.** Any unrecognized attributes in the incoming request payload MAY be safely ignored by the server.

**A.** 뜻: 수신된 요청 페이로드에서 인식되지 않는 임의의 속성은 서버에 의해 안전하게 무시될 수 있다.

구문 패턴: 'MAY be [past participle]' (~될 수 있다 / 허용됨)
- 표준 문서에서 필수 구현 사항이 아니며, 시스템이 해당 동작을 수행해도 규격 위반이 아닌 선택적(Optional) 처리 방식을 나타낼 때 사용합니다.

**Q.** The state of the pod shall remain unchanged until all lifecycle hooks have completed execution.

**A.** 뜻: 모든 라이프사이클 훅의 실행이 완료될 때까지 파드의 상태는 변경되지 않은 채 유지되어야 한다.

구문 패턴: 'shall remain [adjective/unchanged]' (~한 상태를 유지해야 한다)
- 특정 전제 조건이 충족될 때까지 특정 상태나 상태값이 변경되지 않고 유지되어야 한다는 조건부 의무 구문입니다.

**Q.** The namespace parameter MUST be specified when querying cluster-scoped resources via the REST API.

**A.** 뜻: REST API를 통해 클러스터 범위 리소스를 조회할 때는 네임스페이스 파라미터가 반드시 지정되어야 한다.

구문 패턴: 'MUST be [past participle] when [condition]' (~할 때 반드시 ~되어야 한다)
- RFC 2119 / 3GPP 규격에서 시스템 동작 시 반드시 충족해야 하는 조건적 절대 요구사항(MUST)을 기술할 때 활용됩니다.

## GitHub 소통 문구

**Q.** PR 리뷰 중, '이 이슈가 해결되기 전까지는 머지할 수 없는 블로킹 이슈입니다'라고 알리고 싶을 때

**A.** 영어 표현: 'This issue is a blocker for merging this PR.'

유사 표현:
- 'This needs to be resolved before we can proceed with merging.'
- 'We should hold off on merging until this is fixed.'

사용 상황: 치명적인 버그나 신중히 검토해야 하는 Breaking Change가 있어 해당 수정건이 해결되기 전까지 머지를 보류해야 함을 설명할 때 씁니다.

**Q.** PR 본문을 적을 때, '이해를 돕기 위해 코드 변경의 맥락과 배경을 설명에 추가했습니다'라고 전달하고 싶을 때

**A.** 영어 표현: 'I've added some background context in the PR description for better readability.'

유사 표현:
- 'Included a brief summary of why this change was made.'
- 'Added some technical context to help with the review.'

사용 상황: 코드 내용만으로는 변경 이유를 한눈에 알아보기 힘들 때, 이슈 배경이나 의도를 PR 본문에 보충했음을 알릴 때 사용합니다.

## 생활영어

**Q.** 새로 도입한 기술이나 도구에 익숙해져서 '이제 좀 감을 잡았어 / 익숙해졌어'라고 말하고 싶을 때

**A.** 영어 표현: 'I think I'm finally getting the hang of it.'

뉘앙스 설명:
'get the hang of [something]'은 반복적인 시도나 연습 끝에 특정 도구, 시스템, 노하우의 사용법이나 감을 터득했을 때 자연스럽게 쓰는 대표적인 일상 대화 표현입니다.
