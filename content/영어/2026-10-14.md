# 2026-10-14 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** Any modification to the resource spec MUST be accompanied by a corresponding update to the status subresource.

**A.** 뜻: 리소스 스펙에 대한 모든 변경은 그에 대응하는 상태 서브리소스 업데이트를 반드시 동반해야 한다.

구문 패턴 설명: 'MUST be accompanied by ~'는 규약 문서나 공식 API 사양에서 어떤 변경/작업이 발생할 때 불가분하게 함께 이루어져야 하는 필수 조건이나 종속 작업을 규정할 때 쓰입니다. RFC/3GPP 기준 'MUST'는 엄격한 필수 의무 사항을 의미합니다.

**Q.** The temporary identifier shall be derived from the permanent identity using the designated hash algorithm.

**A.** 뜻: 임시 식별자는 지정된 해시 알고리즘을 사용하여 영구 식별자로부터 도출되어야 한다.

구문 패턴 설명: 'shall be derived from ~'는 특정 데이터나 식별자가 어떤 원본 정보로부터 산출/생성되어야 함을 나타내는 표준 규격 표현입니다. 'shall'은 사양 준수를 위해 반드시 따라야 하는 강제성 요구사항(Mandatory)을 뜻합니다.

**Q.** If present, the error detail field shall be populated with a human-readable description of the failure cause.

**A.** 뜻: 존재할 경우, 에러 상세 필드는 실패 원인에 대한 사람이 읽을 수 있는 설명으로 채워져야 한다.

구문 패턴 설명: 'shall be populated with ~'는 데이터 구조체나 API 메시지 페이로드의 특정 필드에 어떤 값/정보를 채워 넣어야 하는지 지시할 때 사용하는 대표적인 기술문서 구문입니다.

**Q.** All control plane signals shall be transmitted via a secure TLS connection.

**A.** 뜻: 모든 제어 평면 신호는 보안 TLS 연결을 통해 전송되어야 한다.

구문 패턴 설명: 'shall be transmitted via ~'는 데이터, 신호, 패킷 등이 통신 체계 내에서 특정 프로토콜이나 채널을 거쳐 전달되어야 함을 명시할 때 3GPP 및 K8s 네트워크 규격에서 활발히 사용됩니다.

## GitHub 소통 문구

**Q.** PR 리뷰 시, 상대방 코드의 작성 의도나 배경 지식이 부담 없이 궁금해서 '단순히 궁금해서 물어보는 건데, 이 방식을 선택하신 이유가 있나요?'라고 물어보고 싶을 때

**A.** 영어 표현: Just out of curiosity, is there a specific reason we went with this approach?
유사 표현: Curiosity question: why choose X over Y? / I'm curious about the motivation behind this.
사용 상황: 상대방 코드가 틀린 것은 아니지만 설계 의도나 대안 대비 선택 이유를 부드럽게 물어보고 싶을 때 비공격적이고 친근하게 질문을 시작하는 관용구입니다.

**Q.** PR 코멘트나 이슈에서 리팩터링 아이디어를 제안한 후 '어떻게 생각하시나요? / 의견 어떠신가요?'라고 피드백을 유도하고 싶을 때

**A.** 영어 표현: What do you think about moving this logic to a middleware? WDYT?
유사 표현: How does this sound to you? / I'd love to hear your thoughts on this.
사용 상황: 자신의 아이디어나 개선안을 올린 뒤 팀원의 반응과 의견을 가볍고 빠르게 물어볼 때 자주 쓰이며, 줄임말인 WDYT(What Do You Think?) 형태로도 많이 작성합니다.

## 생활영어

**Q.** 갑자기 질문을 받았을 때 정확히 찾아보지 않고 '지금 당장 떠오르는 생각으로는 / 내 기억이 맞다면...' 하고 대답을 시작하고 싶을 때

**A.** 영어 표현: Off the top of my head, I think the API rate limit is 100 requests per minute.
뉘앙스 설명: 문서나 데이터를 직접 확인하지 않고 즉석에서 생각나는 기억에 의존하여 답변할 때 쓰는 표현입니다. 확답이 아니라는 부드러운 전제를 깔아주는 효과가 있습니다.

## 단어
