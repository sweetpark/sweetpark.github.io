# 2026-11-26 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** All incoming requests SHALL be evaluated prior to any authentication checks.

**A.** 뜻: 모든 수신 요청은 인증 확인보다 먼저 평가되어야 한다.
구문 패턴: `SHALL be evaluated prior to [event/action]` (~보다 먼저/우선하여 평가되어야 함).
스펙 용어 노트: `SHALL`은 표준 스펙 문서에서 강제 사항(Mandatory)을 뜻하며 `MUST`와 동일한 격을 갖습니다. `prior to`는 `before` 대신 기술 문서나 규격서에서 주로 사용되는 격식 있는 표현입니다.

**Q.** The fallback parameter SHOULD NOT be specified unless the primary endpoint is unreachable.

**A.** 뜻: 주 엔드포인트에 도달할 수 없는 경우가 아니라면 폴백 파라미터를 지정하지 않는 것이 권장된다.
구문 패턴: `SHOULD NOT [verb] unless [condition]` (~한 경우가 아니라면 ~하지 않는 것이 권장됨).
스펙 용어 노트: `SHOULD NOT`은 권장하지 않음(Recommended against)을 나타냅니다. 예외 조건(`unless`)을 명시하여 특정 상황에서만 예외적 사용이 허용됨을 규정할 때 사용합니다.

**Q.** The session identifier SHALL be considered valid if and only if it matches an active token in the cache.

**A.** 뜻: 세션 식별자는 캐시 내의 활성 토큰과 일치하는 경우에만 유효한 것으로 간주되어야 한다.
구문 패턴: `SHALL be considered [status] if and only if [condition]` (오직 ~할 때에만 ~한 상태로 간주됨).
스펙 용어 노트: `if and only if`는 필요충분조건(Strict condition)을 명시할 때 사용하는 대표적인 수학적/스펙용 논리 표현입니다.

**Q.** Events originating from the same stream SHALL be processed in the order received.

**A.** 뜻: 동일한 스트림에서 발생한 이벤트는 수신된 순서대로 처리되어야 한다.
구문 패턴: `SHALL be processed in the order received` (수신된 순서대로 처리되어야 함).
스펙 용어 노트: 메시지 큐, K8s 컨트롤러 이벤트 핸들링, 3GPP 시그널링 등 순서 보장(Ordering Guarantee)이 필요한 스펙 항목에서 표준적으로 쓰이는 구문입니다.

## GitHub 소통 문구

**Q.** PR 리뷰 중 상대방 코드의 특정 로직이 왜 필요하고 어떻게 동작하는지 가볍게 설명해달라고 요청하고 싶을 때

**A.** 영어 표현: "Could you clarify the reasoning behind this part?"
유사 표현: "Could you walk me through why this is needed here?"
사용 상황: PR 리뷰 코멘트에서 코드 작성자의 의도나 로직의 배경을 친절하게 되물어볼 때 사용합니다.

**Q.** 변경사항이 너무 커져서 리뷰어의 부담을 줄이기 위해 PR을 여러 개로 나누어 다시 올리겠다고 말할 때

**A.** 영어 표현: "I'll break this down into smaller PRs for easier review."
유사 표현: "I'll split this change into separate PRs to keep things manageable."
사용 상황: 리뷰용 코드가 너무 많을 때, 리뷰어를 배려하여 더 작은 단위로 분할하겠다는 계획을 남길 때 사용합니다.

## 생활영어

**Q.** 업무나 코딩에 깊이 몰입해서 시간 가는 줄 모르고 엄청난 집중력을 발휘했을 때

**A.** 영어 표현: "I was totally in the zone."
뉘앙스 설명: 'in the zone'은 스포츠 선수나 개발자가 최고조의 집중 상태(몰입 상태, Flow)에 빠져 주위 환경이나 시간을 잊고 작업에 완전히 빠져든 상태를 말합니다.
