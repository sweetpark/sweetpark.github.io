# 2026-10-12 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The status updates shall be executed in sequence to prevent state race conditions.

**A.** 뜻: 상태 업데이트는 상태 경쟁 조건을 방지하기 위해 순차적으로 실행되어야 한다.

구문 패턴 설명:
'shall be executed in sequence'는 스펙 문서에서 동작의 순서(sequence)를 강제할 때 자주 사용되는 필수(Mandatory) 규정 구문입니다.
- SHALL: 스펙상의 필수 요구사항 (Mandatory)
- in sequence: 순차적으로, 정해진 순서대로

**Q.** The container SHOULD be configured with resource limits to prevent resource starvation.

**A.** 뜻: 리소스 고갈을 방지하기 위해 컨테이너에 리소스 제한을 설정하는 것이 권장된다.

구문 패턴 설명:
'SHOULD be [과거분사]' 구문은 기술 표준이나 공식 문서에서 강제사항(SHALL)은 아니지만 권장되는 최선의 관례(Best Practice)를 기술할 때 사용합니다.
- SHOULD: 권장 사항 (강제는 아니나 정당한 이유가 없는 한 준수해야 함)
- configure with: ~를 설정/구성하다

**Q.** The authorization header MAY be omitted when mutual TLS authentication is active.

**A.** 뜻: 상호 TLS 인증이 활성화되어 있는 경우 인증 헤더는 생략될 수 있다.

구문 패턴 설명:
'MAY be omitted'는 특정 조건하에서 파라미터나 절차가 선택적(Optional)임을 나타낼 때 사용합니다.
- MAY: 선택 사항 (허용됨, Optional)
- omit: 생략하다, 누락시키다

**Q.** The network function shall update its internal routing table where applicable.

**A.** 뜻: 해당 네트워크 기능은 해당되는 경우(적절한 경우) 자체 내부 라우팅 테이블을 업데이트해야 한다.

구문 패턴 설명:
'where applicable'은 특정 조건이나 상황이 적용되는 경우에만 해당 요구사항을 이행하라는 단서 조항을 붙일 때 기술 문서에서 매우 흔히 쓰이는 관용구입니다.

## GitHub 소통 문구

**Q.** 이 변경 사항이 왜 필요한지 PR 설명에 맥락을 조금 더 추가해 주실 수 있나요?

**A.** 영어 표현:
"Could you add a bit more context in the PR description regarding why this change is necessary?"

유사 표현:
- "Could you elaborate a bit more on the motivation behind this PR?"
- "Would you mind providing some context for this change?"

사용 상황:
PR의 목적이나 배경 지식이 명확하지 않아 코드 수정 이유를 이해하기 어려울 때 정중하게 맥락 설명을 요청하는 표현입니다.

**Q.** 제안해 주신 방식을 적용해서 새로 커밋을 올렸습니다.

**A.** 영어 표현:
"I've pushed a commit applying the suggested approach."

유사 표현:
- "Pushed a fix following your suggestion."
- "Updated the code as suggested in the latest commit."

사용 상황:
리뷰어가 피드백으로 제안한 모범 사례나 구조 방식을 코드에 반영하여 수정 커밋을 올렸음을 알릴 때 쓰는 깔끔한 댓글 표현입니다.

## 생활영어

**Q.** 잠시만 기다려 주세요, 거의 다 끝났습니다.

**A.** 영어 표현:
"Bear with me for a second, I'm almost done."

뉘앙스 설명:
'Bear with me'는 상대방에게 '잠시 참고 기다려 달라'고 정중하게 부탁할 때 자주 쓰이는 표현입니다. 미팅 중 화면 공유를 준비하거나 작업을 마무리하는 동안 상대방에게 양해를 구할 때 유용합니다.

## 단어

**Q.** deterministic

**A.** 뜻:
결정론적인, 확정적인 (동일한 입력에 대해 항상 동일한 결과를 출력하는)

예문:
"We need to ensure that the test execution order is deterministic to prevent flaky tests."
(간헐적인 테스트 실패를 방지하려면 테스트 실행 순서가 확정적이어야 합니다.)
