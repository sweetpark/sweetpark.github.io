# 2026-11-28 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** A new event log SHALL be generated whenever a Pod state transition occurs.

**A.** 뜻: Pod 상태 전이가 발생할 때마다 새로운 이벤트 로그가 생성되어야 한다.

구문 패턴: 'SHALL be [과거분사] whenever [조건문]' 패턴은 특정 이벤트나 조건이 발생할 때 시스템이 반드시 수행해야 하는 조건부 필수 동작을 규정합니다.

표준 규격 비교 (RFC 2119/3GPP):
- SHALL (MUST와 동일): 규격 준수를 위한 강제 필수 사항
- SHOULD: 강력히 권장되나 정당한 사유가 있다면 예외 허용
- MAY: 구현 여부가 선택적인 옵션 항목

**Q.** The controller SHOULD NOT be configured to poll the API server at intervals shorter than 5 seconds.

**A.** 뜻: 컨트롤러가 5초보다 짧은 주기 간격으로 API 서버를 폴링하도록 설정해서는 안 된다.

구문 패턴: 'SHOULD NOT be configured to [동사원형]'은 성능 저하나 과부하 등을 방지하기 위해 특정 구성 설정을 하지 말 것을 강력히 권장할 때 쓰입니다.

표준 규격 비교:
- SHOULD NOT: 부작용 방지를 위해 지양하라는 권고사항 (완전 금지인 SHALL NOT보다 부드러운 뉘앙스)
- SHALL NOT: 절대로 허용되지 않는 금지 규정

**Q.** An explicit timeout parameter MAY be specified in lieu of the default system expiration duration.

**A.** 뜻: 기본 시스템 만료 시간 대신 명시적인 타임아웃 파라미터를 지정할 수 있다.

구문 패턴: 'MAY be [과거분사] in lieu of [대체 대상]'은 기존 기본 동작이나 값 대신 대체 옵션을 선택적으로 지정할 수 있음을 나타냅니다.

구문 요소:
- in lieu of: 스펙 및 법률 문서에서 'instead of' 대신 자주 쓰이는 포멀한 표현
- MAY: 선택적 기능 권한 부여

**Q.** Requests containing unparseable payload structures SHALL be rejected with an appropriate status code.

**A.** 뜻: 파싱할 수 없는 페이로드 구조를 포함하는 요청은 적절한 상태 코드와 함께 거부되어야 한다.

구문 패턴: 'SHALL be rejected with [사유/결과]'는 유효성 검사 실패나 에러 상황 시 시스템이 반드시 취해야 하는 거부 동작 및 반환 방식을 정의합니다.

표준 규격 비교:
- SHALL be rejected: 예외 없이 즉시 에러 처리 및 거부해야 함을 명시

## GitHub 소통 문구

**Q.** PR 리뷰 중 상대방의 코드 구현 방식이나 로직에 특별한 이유나 의도가 있는지 예의 바르고 궁금하게 물어보고 싶을 때 뭐라고 말할까요?

**A.** 영어 표현: "Is there a specific reason for handling it this way?" / "Just curious about the rationale behind this approach."

유사 표현:
- "Could you share the reasoning behind this design decision?"
- "Was there a particular edge case in mind for this setup?"

사용 상황: 코드가 다소 비효율적이거나 이례적으로 보일 때, 비판 대신 숨겨진 배경 사정이나 의도를 지혜롭게 확인할 수 있습니다.

**Q.** 리뷰어의 제안에 따라 코드를 수정하고, 로컬 환경에서 검증/테스트까지 마쳤음을 댓글로 알려줄 때 뭐라고 말할까요?

**A.** 영어 표현: "Updated as suggested and verified with local tests."

유사 표현:
- "Applied the recommended changes and confirmed all tests pass."
- "Addressed your feedback and verified the behavior in my local environment."

사용 상황: 리뷰 피드백 반영 후 수정사항과 함께 검증 완료 상태를 깔끔하고 명확하게 피드백할 때 사용합니다.

## 생활영어

**Q.** 개발이나 일에 너무 몰입해서 시간 가는 줄 모르고 있다가 벌써 퇴근 시간이 된 것을 깨달았을 때 자연스럽게 할 수 있는 말은?

**A.** 영어 표현: "I completely lost track of time!"

뉘앙스 설명: 'lose track of ~'는 ~을 놓치거나 잊어버리는 것을 의미합니다. 업무나 어떤 활동에 완전히 몰두하여 시간 감각을 잃었을 때 일상 및 오피스 대화에서 매우 빈번하게 쓰입니다.

## 단어

**Q.** monotonic

**A.** 뜻: 단조로운, (수학/전산) 단조 증가/감소하는 (값이 줄어들지 않고 계속 늘어나거나 유지되는)

예문: "Using a monotonic clock ensures that calculated elapsed time is unaffected by system clock adjustments."
(단조 시계를 사용하면 계산된 경과 시간이 시스템 시계 조정의 영향을 받지 않도록 보장합니다.)
