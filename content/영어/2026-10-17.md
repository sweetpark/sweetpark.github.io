# 2026-10-17 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The 'timeout' parameter MUST NOT be used in conjunction with the 'async' flag.

**A.** 뜻: 'timeout' 파라미터는 'async' 플래그와 함께 사용되어서는 안 된다.

구문 패턴: MUST NOT be used in conjunction with (~와 함께/동시에 사용되어서는 안 된다)
- 서로 양립할 수 없거나 상호 배제적인 옵션/파라미터를 기술 문서에서 규정할 때 주로 쓰입니다.
- RFC 2119 / 3GPP 명세에서 'MUST NOT'은 절대 허용되지 않는 완전한 금지 사항을 나타냅니다.

**Q.** The payload SHALL be formatted as a JSON object, unless indicated otherwise in the API specification.

**A.** 뜻: API 명세서에 달리 표시되지 않는 한, 페이로드는 JSON 객체 형태로 서식이 지정되어야 한다.

구문 패턴: unless indicated otherwise (~라고 달리 표시/지시되지 않는 한)
- 예외 규정이나 예외적 상황을 명시할 때 쓰는 표현입니다.
- 'SHALL'은 필수적으로 이행해야 하는 강제 규정(Mandatory)을 의미합니다.

**Q.** Health check evaluations SHALL be performed on a per-node basis.

**A.** 뜻: 헬스 체크 평가는 노드 단위로(노드별로) 수행되어야 한다.

구문 패턴: on a per-X basis (~ 단위로 / ~별로)
- 수행 단위나 처리 범위를 분명하게 규정할 때 Kubernetes 및 3GPP 스펙에서 자주 쓰이는 패턴입니다. (예: on a per-pod basis, on a per-request basis)
- 'SHALL'은 시스템이 반드시 만족해야 하는 요구사항을 뜻합니다.

**Q.** If the field is not present, the attribute SHALL be initialized to zero.

**A.** 뜻: 해당 필드가 존재하지 않을 경우, 특성값은 0으로 초기화되어야 한다.

구문 패턴: SHALL be initialized to (~로 초기화되어야 한다)
- 누락된 파라미터나 초기 상태 객체의 기본값 할당 동작을 스펙상 명확히 정의할 때 쓰입니다.
- RFC 2119 규정상 'SHALL'은 의무 사항입니다.

## GitHub 소통 문구

**Q.** PR 리뷰 중 '혹시 내가 잘못 이해했거나 놓친 부분이 있다면 편하게 알려주세요'라고 정중하게 말하고 싶을 때

**A.** 표현: Correct me if I'm wrong, but...

유사 표현:
- Let me know if I misunderstood anything.
- Please feel free to correct me if I missed something.

사용 상황: 상대방의 코드나 로직에 대해 피드백을 주면서, 내가 오해했을 가능성을 염두에 두고 정중하게 질문을 던질 때 유용합니다.

**Q.** 리뷰어나 동료가 제안한 방식이 더 좋아서 '좋은 제안이네요! 말씀해주신 방향으로 반영해서 진행하겠습니다'라고 응답할 때

**A.** 표현: I like this approach. I'll go ahead with that.

유사 표현:
- That sounds like a much cleaner approach. I'll update the PR accordingly.
- Great suggestion! I'll follow this direction.

사용 상황: 리뷰 피드백에서 더 나은 가이드나 우아한 해결책을 제안받았을 때, 이에 동의하며 작업에 착수하겠다는 의사를 밝힐 때 사용합니다.

## 생활영어

**Q.** 상대방의 설명이나 의견을 듣고 '네가 왜 그렇게 생각하는지/말하는지 그 입장이 이해가 된다'라고 공감하며 말할 때

**A.** 표현: I see where you're coming from.

뉘앙스 설명:
- 단순히 사실을 이해했다는 'I understand'를 넘어, 상대방의 상황, 배경, 맥락에 공감하여 '무슨 뜻/느낌으로 한 말인지 알겠다'는 인정을 담아 표현할 때 자주 쓰입니다.

## 단어

**Q.** caveat

**A.** 뜻: (특정 행동·제안 시의) 경고, 주의사항, 조건

예문: There is one caveat to this approach: it increases memory usage significantly.
(이 접근 방식에는 한 가지 주의사항이 있습니다. 메모리 사용량이 크게 증가한다는 점입니다.)
