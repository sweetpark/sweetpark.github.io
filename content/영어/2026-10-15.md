# 2026-10-15 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The detailed encoding format of the Information Element shall be specified in TS 38.331.

**A.** 뜻: 해당 정보 요소(IE)의 상세 인코딩 형식은 TS 38.331에 규정되어야 한다.

구문 패턴 설명: 'shall be specified in [문서/절]'은 3GPP 표준 규격서나 기술 사양 문서에서 특정 세부 구현이 다른 기술 문서에 정의되어 있음을 명시하는 대표적인 참조 표현입니다. 필수 규격(SHALL)을 지정할 때 자주 등장합니다.

**Q.** The configuration guidelines described in this section shall be applicable to all worker nodes.

**A.** 뜻: 이 절에 설명된 구성 가이드라인은 모든 워커 노드에 적용되어야 한다.

구문 패턴 설명: 'shall be applicable to ~'는 명시된 대상이나 조건 전체에 해당 규격/규칙이 적용된다는 강제적 범위를 지정할 때 사용됩니다.

**Q.** If the header checksum verification fails, the received packet shall be discarded immediately.

**A.** 뜻: 헤더 체크섬 검증에 실패하면, 수신된 패킷은 즉시 폐기되어야 한다.

구문 패턴 설명: 'shall be discarded'는 3GPP 및 K8s 네트워킹 스펙에서 유효하지 않거나 오류가 발생한 PDU/패킷/메시지를 시스템이 어떻게 처리해야 하는지(드롭/삭제)를 규정하는 수동태 표현입니다.

**Q.** Resource request limits can be configured on a per-container basis within the Pod specification.

**A.** 뜻: 리소스 요청 제한은 Pod 스펙 내에서 컨테이너 단위로 설정할 수 있습니다.

구문 패턴 설명: 'on a per-[resource] basis'는 '~단위로', '~별로'라는 의미의 대표적인 기술 문서 표현입니다. (예: on a per-node basis, on a per-session basis)

## GitHub 소통 문구

**Q.** 이 변경사항이 기존 기능에 영향을 주지 않는 하위 호환 가능한 수정임을 PR 설명에 밝히고 싶을 때

**A.** 영어 표현: This change is backward compatible and won't affect existing behavior.
유사 표현: This is a non-breaking change, so existing features should remain unaffected.
사용 상황: PR 설명 작성 시 기존 동작을 깨뜨리지 않는 안전한 수정임을 리뷰어에게 확신시키고자 할 때 사용합니다.

**Q.** 리뷰어 피드백을 반영하면서 관련 테스트 케이스도 함께 추가했다고 코멘트를 남기고 싶을 때

**A.** 영어 표현: I've added test cases to cover this scenario.
유사 표현: Included unit tests to verify this edge case.
사용 상황: 리뷰에서 지적받은 예외 상황이나 변경 건에 대한 커버리지를 검증하는 테스트 코드를 포함했음을 알릴 때 사용합니다.

## 생활영어

**Q.** 화상 회의 중 상대방 음성이 중간에 끊겨서 마지막 말을 못 들었을 때 다시 말해달라고 요청하고 싶을 때

**A.** 영어 표현: You broke up for a second. Could you repeat the last part?
뉘앙스 설명: 'break up'은 통화나 음성 연결이 지직거리거나 끊기는 현상을 뜻합니다. 상대방의 실수가 아닌 통신 상태 문제로 못 들었음을 정중하게 알리며 재요청할 때 매우 자연스러운 표현입니다.
