# 2026-09-26 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The behavior is undefined if multiple controllers attempt to update the same resource simultaneously.

**A.** 뜻: ~하는 경우 동작이 정의되지 않음 (결과를 보장할 수 없음)
구문 설명: 규격서나 기술 문서에서 예외적인 상황이나 미지원 조합에 대해 표준 동작을 보장하지 않음을 명시할 때 사용하는 표현입니다.
관련 비교: 'shall be rejected'처럼 명시적 에러를 내는 대신, 시스템마다 동작이 다를 수 있음을 나타냅니다.

**Q.** The 'hostNetwork' and 'hostIPC' settings shall be mutually exclusive with the strict container isolation policy.

**A.** 뜻: 상호 배타적이어야 한다 (동시에 선택/설정될 수 없다)
구문 설명: 두 개 이상의 옵션이나 필드가 동시에 양립할 수 없음을 규정할 때 씁니다.
관련 비교: RFC/3GPP 스펙에서 MUST NOT be used together와 동일한 수준의 강한 제약을 나타냅니다.

**Q.** Upon successful authentication, the server MAY optionally include additional user profile metadata in the response payload.

**A.** 뜻: 선택적으로 ~를 포함할 수 있다
구문 설명: 수신자나 구현체에게 특정 데이터를 포함하거나 생략할 수 있는 자율적인 권한(선택 사항)을 부여할 때 쓰입니다.
관련 비교: SHOULD(권장)와 달리 MAY는 순수한 선택 사항(Optional)임을 강조합니다.

**Q.** Any unrecognized query parameters in the API request shall be treated as invalid request attributes.

**A.** 뜻: ~로 간주되어 처리되어야 한다
구문 설명: 특정 상태나 입력 데이터를 어떻게 취급하고 응답해야 하는지 처리 방식을 명시할 때 씁니다.
관련 비교: 'shall be deemed'가 법적/규약적 간주에 가깝다면, 'shall be treated as'는 실질적인 시스템 처리 로직을 지칭합니다.

## GitHub 소통 문구

**Q.** 작업 중인 브랜치에 최신 main 브랜치 변경사항을 rebase(또는 merge)해서 충돌을 해결해 달라고 요청할 때 뭐라고 말하지?

**A.** 영어 표현: Could you rebase your branch onto main to resolve the conflict?
유사 표현: Please sync your branch with the latest main.
사용 상황: PR에 충돌(conflict)이 발생했거나 최신 메인 브랜치 변경사항 반영이 필요할 때 친절하게 재베이스를 요청하는 표현입니다.

**Q.** 코드 리뷰나 이슈 답변을 남긴 후 '제 설명이 명확했기를 바라며, 궁금한 점이 있으면 말씀해주세요'라고 친절하게 마무리할 때 뭐라고 말하지?

**A.** 영어 표현: Hope this clarifies things! Let me know if you have any questions.
유사 표현: Let me know if anything is still unclear.
사용 상황: 리뷰 피드백이나 기술적 설명을 작성한 뒤 상대방의 이해 여부를 확인하고 추가 질의응답을 유도할 때 쓰는 자연스러운 마무리 문구입니다.

## 생활영어

**Q.** 상대방의 말이 잘 안 들렸거나 빠르게 지나갔을 때 '죄송하지만 방금 하신 말씀을 잘 못 들었어요'라고 정중하게 다시 요청할 때 뭐라고 말하지?

**A.** 영어 표현: Sorry, I didn't quite catch that. Could you say that again?
뉘앙스 설명: 'What?'이나 'Pardon?'보다 훨씬 부드럽고 자연스럽게 상대방의 말을 다시 확인하는 대표적인 일상 대화 표현입니다.
