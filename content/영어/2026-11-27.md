# 2026-11-27 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The controller SHALL transition the Pod state to Terminating upon receiving a deletion request.

**A.** 뜻: 컨트롤러는 삭제 요청을 수신하는 즉시 Pod 상태를 Terminating으로 전이(전환)해야 한다.

[구문 패턴 설명]
- transition [A] state to [B]: A의 상태를 B로 전환/전이하다.
- 기술 문서 및 스펙 문맥에서 'transition'은 상태 머신(State Machine)상 한 상태에서 다른 상태로 명확히 넘어갈 때 자주 사용됩니다.
- 'upon receiving': ~를 수신하는 즉시/수신하자마자 ('upon + 동명사' 패턴).

**Q.** If the requested memory limit exceeds the maximum allowable threshold, the API server SHALL reject the request with HTTP status code 422.

**A.** 뜻: 요청된 메모리 제한이 허용된 최대 임계값을 초과하는 경우, API 서버는 HTTP 상태 코드 422와 함께 요청을 거부해야 한다(SHALL).

[구문 패턴 설명]
- exceed the maximum allowable threshold: 허용 가능한 최대 임계치를 초과하다.
- 스펙 표준에서 'allowable'은 상한/하한 등의 한계(threshold)나 오차 범위(tolerance)를 정의할 때 주로 붙는 표준 형용사입니다.

**Q.** The User Plane Function (UPF) SHALL retain the session context until explicitly notified of session release.

**A.** 뜻: UPF는 세션 해제를 명시적으로 통보받을 때까지 세션 컨텍스트를 유지해야 한다(SHALL).

[구문 패턴 설명]
- explicitly notified of [something]: ~를 명시적으로 통지/통보받다.
- 3GPP/K8s 스펙에서는 타이머 만료나 암묵적 해제가 아닌, 명시적인 시그널링 수신 시점까지 상태를 유지해야 함을 정밀하게 기술할 때 'until explicitly notified of' 구문을 사용합니다.

**Q.** Replicas SHOULD be evenly distributed across available failure domains to ensure high availability.

**A.** 뜻: 고가용성을 보장하기 위해 레플리카는 사용 가능한 장애 도메인(노드/존 등)에 균등하게 분배되어야 한다(SHOULD).

[구문 패턴 설명]
- evenly distributed across [domains/nodes]: ~에 걸쳐 균등하게 분배되다.
- 쿠버네티스의 Topology Spread Constraints나 Pod Anti-affinity 스펙 기술 시 빈번히 쓰이는 관용적 표현입니다.
- SHALL(강제 필수)이 아닌 SHOULD(권장 사항)가 사용되어, 불가피한 환경적 제약 시 균등 분배되지 않을 수도 있음을 나타냅니다.

## GitHub 소통 문구

**Q.** PR 변경 사항을 코드 눈으로만 보지 않고, 제 local 개발 환경으로 브랜치를 가져와서 직접 테스트해보는 중이라고 알리고 싶을 때

**A.** 영어 표현: I'm currently pulling down your branch to test it locally.

유사 표현:
- I'm checking out your branch locally to verify the behavior.
- Pulling this locally to give it a spin.

사용 상황: PR 리뷰 중 코드를 눈으로 보는 것만으로는 부족하여 직접 local 환경에서 빌드/실행해 보며 검증 중임을 알릴 때 사용합니다.

**Q.** 다른 PR이 먼저 머지되면서 내 PR에 충돌(conflict)이 발생했을 때, main 브랜치를 rebase해서 충돌을 해결하겠다고 알리고 싶을 때

**A.** 영어 표현: I'll rebase onto main and resolve the merge conflicts shortly.

유사 표현:
- Looks like there are conflicts with main. Fixing them now.
- Syncing with main to clear up the conflicts.

사용 상황: PR 탭에서 conflict 경고가 떴거나 리뷰어가 브랜치 동기화/충돌 해결을 요청했을 때 조치할 예정임을 공유하는 표현입니다.

## 생활영어

**Q.** 상대방의 해명이나 배경 설명을 듣고 나서 '그 맥락을 들으니 이제야 상황이 제대로 이해되네'라고 말하고 싶을 때

**A.** 영어 표현: That puts things into perspective.

뉘앙스 설명:
새로운 정보나 배경 설명을 통해 전체적인 맥락을 비로소 제대로 이해하게 되었을 때 쓰는 표현입니다. 섣부른 판단을 바로잡고 상황을 더 넓은 관점에서 이해하게 되었다는 긍정적이고 정중한 공감의 어조를 띱니다.

예시: "Ah, I didn't realize we had that legacy database limitation. That puts things into perspective!"

## 단어

**Q.** 메시지 큐나 이벤트 기반 아키텍처에서 중복 수신된 데이터나 메시지를 '중복 제거하다'라는 뜻의 동사

**A.** 뜻: 중복을 제거하다 (동사)

예문: The consumer service should deduplicate incoming messages based on the message ID to avoid processing the same payload twice.

설명: deduplication(중복 제거)의 동사 형태입니다. 백엔드 분산 시스템에서 메시지 재전송(at-least-once delivery) 이슈나 이중 요청을 처리할 때 필수적으로 등장하는 단어입니다.
