# 2026-11-08 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The controller SHALL NOT attempt to re-queue the resource pending the resolution of the underlying configuration conflict.

**A.** 뜻: ~이 해결될 때까지 / ~을 기다리는 동안

구문 패턴 설명: 'pending + 명사구'는 특정 조건이나 문제 상황이 해결되어 마무리될 때까지 후속 동작을 대기시키거나 보류할 때 규격 문서에서 빈번하게 쓰이는 표준 구문 패턴입니다.

관련 비교:
- SHALL NOT: 엄격한 금지 조항을 나타내며, 갈등 조건이 해결되기 전에 재큐잉하는 동작을 금지합니다.
- 유사 표현: 'until ... is resolved'보다 격식 있고 간결한 스펙 문서용 표기입니다.

**Q.** If the requested node pool capacity is unavailable, the scheduler SHALL failover to a secondary availability zone.

**A.** 뜻: ~로 장애 조치(페일오버)하다 / 대체 시스템으로 전환하다

구문 패턴 설명: 'failover to + 대상'은 주 인프라나 자원에 장애 또는 용량 부족이 발생했을 때 예비 시스템이나 다른 영역으로 자동 전환하는 동작을 서술할 때 사용됩니다.

관련 비교:
- SHALL: 시스템 규격 준수를 위한 필수(Mandatory) 동작을 지정합니다.
- fallback to가 일반적인 기본값 복귀나 유연한 대안 선택을 의미하는 반면, failover to는 인프라 수준의 장애 복구 전환에 주로 쓰입니다.

**Q.** The field value SHALL be strictly non-negative.

**A.** 뜻: 엄격히 음수가 아닌 (0 이상인)

구문 패턴 설명: 스펙에서 파라미터 제약조건을 명시할 때 'strictly'를 부사로 붙여 예외 없이 엄격하게 해당 조건 범위를 준수해야 함을 강조하는 패턴입니다.

관련 비교:
- strictly non-negative: 0을 포함한 양수만 허용 (x >= 0)
- strictly positive: 0을 제외한 순수 양수만 허용 (x > 0)

**Q.** A pod SHALL be eligible for dynamic rescheduling if its host node experiences an unrecoverable hardware fault.

**A.** 뜻: ~의 대상이 되다 / ~할 자격·조건에 해당하다

구문 패턴 설명: 특정 자원이나 엔티티가 상태 변화, 스케줄링 재배치, 자원 회수 등의 처리 조건에 부합함을 선언할 때 사용하는 공식 표현입니다.

관련 비교:
- SHALL: 조건을 충족할 경우 해당하는 자격/상태를 정식으로 취득함을 서술합니다.
- subject to가 외부 조치나 통제에 얽매임을 의미하는 반면, be eligible for는 특정 처리를 받을 조건이 충족됨을 의미합니다.

## GitHub 소통 문구

**Q.** PR 리뷰 중, 상대방의 지적이나 제안이 완전히 맞고 내가 착각했다는 것을 인정할 때 표현하고 싶다.

**A.** 영어 표현: "Ah, good point! You're completely right about this."

유사 표현:
- "Sharp eye! I completely missed that edge case."
- "Ah, good catch! I misread the requirements there."

사용 상황: PR 코드 리뷰에서 지적받은 문제점이나 누락 항목이 타당함을 즉시 인정하고 수용할 때 자연스럽게 씁니다.

**Q.** PR 리뷰어에게 '이 부분 구현 방식을 살짝 수정했는데 한번 확인해 주실 수 있나요?'라고 요청하고 싶다.

**A.** 영어 표현: "I've tweaked the implementation a bit. Could you give it a quick look when you have a moment?"

유사 표현:
- "I made a minor adjustment to this part. Let me know what you think."
- "I refactored this section slightly based on your feedback. Would appreciate your thoughts."

사용 상황: 리뷰 피드백을 반영하여 코드의 일부 구현을 살짝 조정한 뒤 리뷰어에게 재확인을 부탁할 때 사용합니다.

## 생활영어

**Q.** 회의 중 한 주제에 대한 논의가 끝나고 다음 안건으로 자연스럽게 넘어가기 위해 '자, 그럼 다음 항목으로 넘어가 볼까요?'라고 말하고 싶다.

**A.** 영어 표현: "Shall we move on to the next item?"

뉘앙스 설명:
- 회의나 세션 진행 중 현재 안건을 깔끔하게 마무리하고 매끄럽게 다음 주제로 참석자들의 주의를 전환할 때 쓰는 정중하고 자연스러운 표현입니다.
- 유사한 표현으로 "Let's move on to the next topic" 또는 "Shall we step into the next item on the agenda?" 등을 사용할 수 있습니다.
