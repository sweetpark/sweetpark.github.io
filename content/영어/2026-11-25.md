# 2026-11-25 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** A Pod SHALL be bound to a single node upon successful scheduling by the control plane.

**A.** 뜻: (노드/자원 등에) 바인딩되다 / 귀속되다.

구문 패턴: 'SHALL be bound to'
'bound to'는 스펙 문서에서 특정 리소스나 엔티티가 다른 대상에 고정되거나 연관 관계를 맺는 상태를 서술할 때 사용됩니다. 'SHALL'은 시스템이 따라야 할 필수 요구사항(Mandatory Requirement)을 나타냅니다.

**Q.** The allocated IP address SHALL NOT be modified during the lifecycle of the PDU session.

**A.** 뜻: ~의 라이프사이클(생명주기) 동안.

구문 패턴: 'during the lifecycle of'
객체, 세션, 컨테이너 등의 생성부터 소멸까지의 전 기간을 지칭하는 관용적 표현입니다. 'SHALL NOT'은 스펙상 엄격히 금지되는 동작(Strictly Forbidden)을 의미합니다.

**Q.** A re-registration procedure SHALL be triggered upon detection of network capability changes.

**A.** 뜻: ~의 감지 즉시 / 감지되는 대로.

구문 패턴: 'upon detection of'
특정 사건이나 상태의 변화가 감지되었을 때 후속 절차가 즉각 유발되는 조건부 동작을 기술할 때 널리 쓰입니다.

**Q.** Custom resource definitions SHALL be scoped exclusively to the cluster level unless defined as namespaced.

**A.** 뜻: 오직 ~ 범위로만 제한된다.

구문 패턴: 'scoped exclusively to'
적용 가능한 대상이나 유효 범위를 엄격하게 제한할 때 쓰이며, 'unless' 조건절과 함께 쓰여 예외 상황을 명확히 정의합니다.

## GitHub 소통 문구

**Q.** 이번 PR에서는 X 기능 구현에만 집중하고, Y 관련 개선 작업은 별도 PR로 나누어 진행하자고 제안하고 싶을 때

**A.** 영어 표현: How about we scope this PR to X and address Y in a separate PR?

- 유사 표현: 'We could limit the scope of this PR to X for now.' / 'Let me know if you'd prefer to handle Y in a follow-up PR.'
- 사용 상황: 리뷰 범위가 너무 커지거나 여러 주제가 섞일 때 관심사를 분리하자고 제안하는 상황에서 사용합니다.

**Q.** 리뷰어가 남긴 피드백이나 해결 제안을 보고 '저도 딱 그렇게 생각하던 참이었습니다!'라고 공감을 표하고 싶을 때

**A.** 영어 표현: I was actually thinking the exact same thing!

- 유사 표현: 'You read my mind.' / 'Great minds think alike!'
- 사용 상황: 상대방의 의견이나 제안이 내 의도나 생각과 정확히 일치할 때 친근감 있게 공감할 때 쓰입니다.

## 생활영어

**Q.** 상대방의 제안에 이해는 가지만, 민감하거나 위험 요소가 있어서 '무슨 뜻인지는 알겠는데 조금 신중하게 접근할 필요가 있겠어요'라고 완곡하게 조언할 때

**A.** 영어 표현: I get your point, but we might want to tread lightly.

- 뉘앙스: 'tread lightly'는 얇은 얼음 위를 걷듯 '신중하고 조심스럽게 행동하다'라는 의미입니다. 상대방의 지적을 수용하면서도 리스크에 대한 주의를 완곡하게 환기할 때 유용합니다.

## 단어

**Q.** Contention

**A.** 뜻: (자원) 경합, 경쟁

- 설명: 여러 동시성 프로세스나 쓰레드가 DB 락, 메모리, CPU 등 동일한 한정 자원에 동시에 접근하려고 다투는 상태를 뜻합니다.
- 예문: High lock contention on the database was causing server response times to spike.
