# 2026-10-29 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The resource name MUST be formatted as a valid DNS subdomain and SHALL NOT be modified once created.

**A.** 뜻: 리소스 이름은 유효한 DNS 서브도메인 형식이어야 하며, 일단 생성된 후에는 수정되어서는 안 된다.

구문 패턴: `MUST be formatted as ~` (~ 형식이어야 한다), `SHALL NOT be modified once ~` (일단 ~되면 수정 불가하다)
- MUST/SHALL: 스펙 문서에서 강제 규정(Mandatory Requirement)을 나타낼 때 사용합니다. 생성 후 불변성(Immutability)을 설명할 때 자주 나오는 구조입니다.

**Q.** Each network slice instance SHALL be uniquely identified by an S-NSSAI.

**A.** 뜻: 각 네트워크 슬라이스 인스턴스는 S-NSSAI에 의해 고유하게 식별되어야 한다.

구문 패턴: `SHALL be uniquely identified by ~` (~에 의해 고유하게 식별되어야 한다)
- 시스템 내부 또는 분산 환경에서 리소스나 엔티티의 유일성(Uniqueness)과 식별자를 정의할 때 3GPP 및 K8s 문서에서 빈번하게 사용됩니다.

**Q.** The maxSurge parameter MAY be specified either as an absolute number or as a percentage of desired pods.

**A.** 뜻: maxSurge 파라미터는 절대적인 개수 또는 희망하는 포드 수의 백분율로 지정될 수 있다.

구문 패턴: `MAY be specified either as A or as B` (A 또는 B 형태로 지정될 수 있다)
- MAY: 선택적 사양(Optional Requirement)을 나타냅니다. 파라미터가 두 가지 이상의 형태로 유연하게 입력될 수 있음을 기술할 때 유용합니다.

**Q.** The keepalive timeout SHOULD be set conservatively to avoid premature connection teardown.

**A.** 뜻: 이른 연결 종료를 방지하기 위해 킵얼라이브 타임아웃은 보수적으로 설정되어야 한다.

구문 패턴: `SHOULD be set conservatively to avoid ~` (~를 피하기 위해 보수적으로/안전하게 설정되어야 한다)
- SHOULD: 권장 사항(Recommendation)을 나타냅니다. 시스템의 안정성을 극대화하기 위한 우수 사례(Best Practice)나 가이드라인을 제시할 때 쓰입니다.

## GitHub 소통 문구

**Q.** PR 리뷰 중 팀원들에게 '이 구현 방식에 대해 혹시 다른 더 좋은 아이디어나 제안이 있으신가요?'라고 부드럽게 의견을 물어보고 싶을 때

**A.** 영어 표현: Open to any suggestions or alternative ideas on this!
유사 표현: Any feedback or alternative approaches would be greatly appreciated. / Do you have any better ideas for this part?
사용 상황: 작성한 코드나 설계 방식에 대해 완전히 확신이 서지 않거나, 팀원들의 더 좋은 아이디어를 적극 수용하고 싶을 때 PR 설명이나 특정 코드 라인 덧글로 작성하기 좋은 표현입니다.

**Q.** 내가 작업할 때는 문제가 없는데, '제 로컬 환경에서는 정상 동작하는데 혹시 다른 분 환경에서도 이 이슈가 재현되나요?'라고 질문할 때

**A.** 영어 표현: Works fine on my local environment. Is anyone else able to reproduce this issue?
유사 표현: It runs without issues on my machine—can anyone replicate this error? / Unable to reproduce locally. Could someone verify if this is happening on your end too?
사용 상황: 버그 리포트나 CI 실패 시, 이슈가 특정 환경에 국한된 문제인지 공통 재현 가능한 문제인지 확인하고 싶을 때 사용합니다.

## 생활영어

**Q.** 상대방과 이야기하다가 '아 참, 깜빡하고 잊고 있었네!'라고 말하고 싶을 때

**A.** 영어 표현: It completely slipped my mind!
뉘앙스 설명: 깜빡하고 완전히 잊어버렸을 때 쓰는 매우 자연스러운 일상 표현입니다. 변명하기보다 솔직하게 건망증이나 순간적인 실수를 인정할 때 가볍게 쓰기 좋습니다. (예: Oh, it completely slipped my mind that we had a meeting today! - 아 참, 오늘 미팅 있는 거 까맣게 잊고 있었네!)

## 단어

**Q.** Bottleneck

**A.** 뜻: 병목 현상, 시스템 전체의 성능이나 처리량을 저하시키는 일부분
예문: We identified a database query that was causing a performance bottleneck during peak hours. (우리는 피크 시간대에 성능 병목 현상을 일으키고 있던 데이터베이스 쿼리를 찾아냈습니다.)
