# 2026-11-11 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The Pod SHALL be considered healthy ONLY IF all readiness probes pass successfully.

**A.** 뜻: 모든 준비성 프로브(readiness probe)가 성공적으로 통과한 경우에만 해당 Pod는 정상(healthy) 상태인 것으로 간주된다.

구문 패턴 설명:
- 'SHALL be considered [상태] ONLY IF [조건]': 강제적 기준(SHALL)을 정의하며, 뒤따르는 조건이 성립할 때만 특정 상태로 인정됨을 명시하는 엄격한 조건식 구문 패턴입니다.
- SHALL vs MAY: SHALL은 반드시 충족해야 하는 필수/강제 규격이고, MAY는 선택적 허용을 나타냅니다.

**Q.** The UE SHOULD NOT re-establish the RRC connection UNLESS specifically instructed by the network.

**A.** 뜻: 단말(UE)은 네트워크로부터 명시적인 지시를 받지 않는 한 RRC 연결을 재설립하지 않는 것이 권장된다.

구문 패턴 설명:
- 'SHOULD NOT [동사] UNLESS [조건]': 권고 조항(SHOULD NOT)으로, 특정한 예외 조건(UNLESS)이 발생하지 않는 한 해당 동작을 피해야 함을 나타냅니다.
- SHOULD NOT vs SHALL NOT: SHOULD NOT은 부득이한 사유가 없을 때 하지 말라는 강한 권고이며, SHALL NOT은 어떠한 경우에도 금지되는 절대적 금지 규정입니다.

**Q.** The state update procedure SHALL be executed asynchronously relative to the event loop.

**A.** 뜻: 상태 갱신 절차는 이벤트 루프와 비동기적으로 수행되어야 한다.

구문 패턴 설명:
- 'asynchronously relative to ~': 두 작업 또는 메커니즘 간의 실행 시점 관계를 명시할 때 사용하는 구조입니다. 특정 메인 프로세스(이벤트 루프 등)의 블로킹을 방지하기 위한 기술 규격에 자주 등장합니다.

**Q.** The parameter SHALL default to zero IF NOT explicitly provided in the request payload.

**A.** 뜻: 요청 페이로드에 해당 파라미터가 명시적으로 제공되지 않은 경우, 기본값은 0으로 설정되어야 한다.

구문 패턴 설명:
- 'SHALL default to [값] IF NOT [조건]': 값이 생략되거나 미지정되었을 때 시스템이 취해야 하는 기본 동작(default behavior)을 규정하는 필수 조항 패턴입니다.

## GitHub 소통 문구

**Q.** 코드 리뷰가 용이하도록 커밋들을 논리적인 단위로 나눠서 구성해 줄 수 있는지 정중하게 요청하고 싶을 때

**A.** 영어 표현: Would you mind organizing these changes into logical commits?
- 유사 표현: Could you group your changes into separate logical commits for easier review?
- 사용 상황: 하나의 커밋에 서로 다른 성격의 변경사항(예: 리팩터링 + 신규 기능 + 오타 수정)이 섞여 있어서 커밋을 분리해달라고 리뷰어로서 부탁할 때 쓰입니다.

**Q.** 리뷰어가 피드백한 코멘트들을 최신 푸시에서 모두 반영했다고 코멘트를 남길 때

**A.** 영어 표현: I've addressed all comments in the latest push.
- 유사 표현: All feedback has been addressed in the latest commit. / Resolved all open comments in this revision.
- 사용 상황: PR 리뷰 지적 사항을 반영하여 코드를 수정 및 푸시한 후, 리뷰어에게 확인 요청을 보낼 때 작성하는 전형적인 문구입니다.

## 생활영어

**A.** 영어 표현: I'm flexible, so whatever works best for you.
