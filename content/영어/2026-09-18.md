# 2026-09-18 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The User Plane Function (UPF) shall comply with the requirements specified in clause 5.2.

**A.** 뜻: UPF는 5.2절에 명시된 요구사항을 준수해야 한다.

구문 패턴: comply with the requirements specified in ~ (~에 명시된 요구사항을 준수하다)
- 표준 규격 문서에서 특정 표준이나 조건절을 반드시 따라야 함을 명시할 때 가장 전형적으로 사용하는 구문입니다.
- 'shall'은 필수 준수 사항(Mandatory)을 의미합니다.

**Q.** If no response is received within the timer interval, the pod shall be deemed unreachable.

**A.** 뜻: 타이머 간격 내에 응답을 받지 못하면, 해당 파드는 도달 불가능한 것으로 간주되어야 한다.

구문 패턴: shall be deemed (to be) ~ (~로 간주되어야 한다 / ~로 본다)
- 명확한 조건 성립 시 특정 상태나 결과로 규정할 때 사용하는 스펙 고유의 구문 표현입니다.
- 'shall'과 결합하여 예외 없이 해당 규정을 적용함을 강조합니다.

**Q.** The controller may select the available endpoints in order of preference.

**A.** 뜻: 컨트롤러는 선호도 순서대로 이용 가능한 엔드포인트를 선택할 수 있다.

구문 패턴: in order of preference (선호도/우선순위 순서대로)
- 다수의 선택지 중 권장 규칙이나 우선순위 정렬 순서에 따라 처리함을 나타낼 때 사용합니다.
- 'may'는 선택적 권한(Optional)을 의미하므로, 구현체에 따라 해당 순서를 따르거나 다른 방식을 택할 수 있습니다.

**Q.** The node update should be executed without disrupting existing workloads.

**A.** 뜻: 노드 업데이트는 기존 워크로드에 지장을 주지 않고 실행되어야 한다.

구문 패턴: without disrupting ~ (~에 지장을 주지 않고 / 중단 없이)
- 서비스 가동 중 수행되는 작업이 기존 시스템에 영향을 미치지 않아야 함을 규정할 때 매우 자주 사용됩니다.
- 'should'는 권고사항(Recommended)을 의미하며, 가능한 한 준수해야 함을 나타냅니다.

## GitHub 소통 문구

**A.** 영어 표현: My bad, I misunderstood the requirements. I'll update this right away.

- Ah, I misread the spec. Fix coming right up!
- Good catch! I totally missed that detail. I'll push a fix shortly.

사용 상황: 리뷰어가 지적한 문제의 원인이 본인의 스펙 이해 부족임을 인정하고 신속히 수정하겠다는 의사를 전달할 때 쓰입니다.

**Q.** 구현한 코드가 너무 복잡해 보여서 리뷰어에게 "더 간단한 방법이 안 떠오르는데 혹시 좋은 제안이 있으신가요?"라고 조언을 구하고 싶다면?

**A.** 영어 표현: This part feels a bit overcomplicated, but I couldn't think of a simpler approach. Any suggestions?

유사 표현:
- I'm open to simpler alternatives if you have any ideas.
- Do you see a cleaner way to handle this?

사용 상황: 자신이 작성한 코드의 복잡성을 인정하고 더 나은 구조나 리팩토링 아이디어를 요청할 때 쓰기 좋은 표현입니다.

## 생활영어

**Q.** 동료나 팀원이 바빠 보여서 "지금 많이 바쁘신 것 같은데 나중에 이야기할까요?"라고 배려하며 물어보고 싶다면?

**A.** 영어 표현: You look a bit caught up right now. Should we chat later?

뉘앙스 설명:
'be caught up (in something)'은 일이나 작업에 얽매여 여유가 없는 상태를 의미합니다. 상대방의 바쁜 상황을 눈치채고 배려하며 대화 시점을 뒤로 미루자고 부드럽게 제안할 때 사용합니다.

## 단어

**Q.** graceful

**A.** 뜻: 우아한, (시스템/프로세스가) 오류나 충격 없이 부드럽고 정상적으로 종료/전환되는

예문: The application performs a graceful shutdown to ensure all in-flight requests are completed before exiting.
