# 2026-11-21 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** State information SHALL be preserved across pod restarts to ensure session continuity.

**A.** 뜻: 세션 연속성을 보장하기 위해 파드 재시작 시에도 상태 정보가 유지되어야 한다 (SHALL).

구문 패턴: [SHALL be preserved across + 이벤트/범위]
- 'preserved across'는 재시작, 노드 이주, 상태 전환과 같은 시스템 이벤트 발생 시에도 데이터나 상태가 유실되지 않고 지속됨을 명시하는 요구사항 표현입니다.
- SHALL: 스펙상 반드시 준수해야 하는 강제 요구사항(Mandatory)입니다.

**Q.** Incoming control plane messages SHALL be dispatched to the designated worker thread based on the message type.

**A.** 뜻: 수신된 제어 평면 메시지는 메시지 유형에 따라 지정된 워커 스레드로 전달/배정되어야 한다 (SHALL).

구문 패턴: [SHALL be dispatched to + 대상]
- 'dispatched to'는 라우팅 장치나 이벤트 루프가 메시지/요청을 적절한 처리 주체(스레드, 핸들러, 노드)로 전송하거나 배정함을 나타내는 표준 표현입니다.
- K8s 커스텀 컨트롤러나 3GPP 프로토콜 메시지 처리 규격에서 빈번하게 사용됩니다.

**Q.** The status of the custom resource SHALL be reconciled against the actual cluster state periodically.

**A.** 뜻: 커스텀 리소스의 상태는 주기적으로 실제 클러스터 상태와 대조되어 일치되어야 한다 (SHALL).

구문 패턴: [SHALL be reconciled against + 기준/상태]
- 'reconciled against'는 K8s의 Reconciliation Loop(조율 루프)에서 관측된 상태(Observed State)를 바라는 상태(Desired State)와 대조 및 합치시키는 동작을 서술할 때 쓰입니다.

**Q.** The transmitted payload SHALL be compliant with the JSON schema specified in 3GPP TS 29.500.

**A.** 뜻: 전송되는 페이로드는 3GPP TS 29.500에 명시된 JSON 스키마를 준수해야 한다 (SHALL).

구문 패턴: [SHALL be compliant with + 규격/표준]
- 'compliant with'는 특정 규격, 데이터 모델, 표준 프로토콜 사양을 온전히 준수하고 충족함을 나타냅니다.
- 동사형인 'comply with'와 동일한 구문적 목적을 가지며, 상태/성격을 서술할 때 주로 활용됩니다.

## GitHub 소통 문구

**Q.** 코드 리뷰 중 대안을 제시하며 "이 기존 메서드를 재사용하는 방향에 대해 어떻게 생각하시나요?"라고 부드럽게 의견을 물어보고 싶을 때

**A.** 영어 표현: "What are your thoughts on reusing this existing method instead?"

사용 상황 및 설명:
- 상대방의 방식을 직접적으로 부정하지 않고, 다른 아이디어나 대안을 제안하며 건설적인 피드백을 주고받을 때 자주 쓰는 질문 형태입니다.
- 유사 표현: "Would you be open to ~?", "What do you think about ~?"

**Q.** 피드백을 읽고 작업을 진행하기 전, "제가 제대로 이해했는지 확인차 여쭤보는데, 결국 ~라는 뜻인가요?"라고 점검하고 싶을 때

**A.** 영어 표현: "Just to double-check, are you suggesting that we should refactor this part?"

사용 상황 및 설명:
- 커뮤니케이션 오류를 방지하고 PR 수정 방향을 명확히 맞추기 위해 내 이해를 다시 점검할 때 매우 유용한 표현입니다.
- 유사 표현: "Just to clarify, do you mean ~?", "To make sure we're on the same page, are you saying ~?"

## 생활영어

**Q.** 수면 부족이나 업무 과로로 에너지가 소진되어 간신히 버티고 있는 상황일 때 ("나 지금 완전히 방전 직전이야.")

**A.** 영어 표현: "I'm running on fumes right now."

뉘앙스 설명:
- 'fumes'는 연료가 거의 바닥나서 남은 가스/연기만을 의미합니다. 자동차가 유증기만으로 간신히 움직이듯, 체력이나 정신력이 한계에 달해 겨우 버티고 있을 때 유머러스하면서도 솔직하게 상태를 표현하는 일상 관용구입니다.

## 단어

**Q.** debounce

**A.** 뜻: 디바운스 (짧은 시간 내에 연달아 발생하는 이벤트를 그룹화하여 마지막(또는 첫) 이벤트만 실행되도록 제어하는 기법)

예문: "We should debounce the search input handler to prevent making unnecessary API calls on every keystroke."
(키를 누를 때마다 불필요한 API 요청을 보내지 않도록 검색 입력 핸들러에 디바운스를 적용해야 합니다.)
