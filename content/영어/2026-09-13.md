# 2026-09-13 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The AMF shall accept the registration request unless otherwise specified in 3GPP TS 23.502.

**A.** 뜻: 3GPP TS 23.502에 별도로 명시되지 않는 한, AMF는 등록 요청을 승인해야 한다 (SHALL).

구문 패턴: 'unless otherwise specified (in ...)' - ~에 달리/별도로 명시되지 않는 한.
규격서 설명: 'shall'은 강제 규정(Mandatory Requirement)을 나타내며, 예외 조건으로 'unless otherwise specified' 구문이 자주 사용됩니다.

**Q.** The pod status is updated upon receipt of the event, subject to resource availability.

**A.** 뜻: 리소스가 사용 가능한 경우에 한해, 이벤트를 수신하는 즉시 Pod 상태가 갱신됩니다.

구문 패턴: 'subject to + 명사' - ~을 전제로 / ~에 따라 (조건절 역할).
관련 비교: 'upon receipt of'는 '~를 수신하자마자/수신 시'를 뜻하는 전치사구로, K8s 컨트롤러 동작이나 3GPP 신호 수신 절차 설명에 빈번히 등장합니다.

**Q.** The node SHOULD log a warning message when the connection is lost, but it SHALL NOT terminate the process automatically.

**A.** 뜻: 노드는 연결이 끊어졌을 때 경고 메시지를 남기는 것이 권장되나(SHOULD), 프로세스를 자동으로 종료해서는 안 된다(SHALL NOT).

스펙 용어 비교:
- SHOULD: 권장 사항 (Recommended, 특별한 이유가 없다면 따르는 것이 권장됨)
- SHALL NOT: 절대 금지 (Absolute Prohibition, 규격 위반)

**Q.** The User Plane Function (hereinafter referred to as UPF) handles packet routing and forwarding.

**A.** 뜻: 유저 플레인 기능(이하 UPF라 함)은 패킷 라우팅 및 포워딩을 처리한다.

구문 패턴: 'hereinafter referred to as ~' - 약어/줄임말을 표준 규격서 도입부에서 정의할 때 쓰는 표현 ('이하 ~라 칭함'). 공식 문서나 표준 스펙 문서의 격식 있는 관용 표현입니다.

## GitHub 소통 문구

**Q.** PR 코드 리뷰할 때, 전체적으로 아주 좋은데 정말 사소한 오타나 스타일 수정 건만 하나 있을 때 뭐라고 하나요?

**A.** 영어 표현: LGTM! Just a small nit: could you fix the typo on line 42?

유사 표현: Looks good to me overall, just one minor nitpick.

사용 상황: 승인(Approve)을 주면서도 굳이 PR을 블로킹할 필요는 없는 사소한(nit/nitpick) 코멘트를 남길 때 사용합니다.

**Q.** PR을 올리거나 수정 반영 후 동료에게 '시간 될 때 리뷰 부탁드려요'라고 부드럽게 요청할 때 뭐라고 하나요?

**A.** 영어 표현: I've addressed all your comments. Mind taking another look when you get a chance?

유사 표현:
- PTAL (Please Take A Look) when you have a moment.
- Ready for re-review!

사용 상황: 리뷰어의 피드백을 반영한 후 재리뷰를 요청하거나, PR 리뷰를 부탁할 때 사용하는 친근하고 매너 있는 표현입니다.

## 생활영어

**Q.** 회의나 일상 대화 중 상대방과 서로 이해한 바가 같은지 확인하면서 '우리 서로 같은 이해(생각)를 하고 있는 거 맞죠?'라고 물어볼 때 뭐라고 하나요?

**A.** 영어 표현: Are we on the same page?

뉘앙스 설명: '같은 페이지를 보고 있다'는 표현에서 유래하여, 어떤 사안에 대해 같은 생각을 하고 있는지, 오해가 없는지 확인할 때 자주 사용하는 일상 및 비즈니스 대화 표현입니다.

## 단어

**Q.** Idempotent

**A.** 뜻: 멱등성의 (연산을 여러 번 적용하더라도 결과가 달라지지 않는 성질)

예문: REST API endpoints designed with the PUT method should be idempotent so that multiple identical requests have the same effect as a single request.
