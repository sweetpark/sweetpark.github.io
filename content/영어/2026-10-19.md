# 2026-10-19 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** Traffic originating from the UE shall be routed to the appropriate UPF based on the packet filter rules.

**A.** 뜻: UE로부터 발생하는 트래픽은 패킷 필터 규칙에 따라 적절한 UPF로 라우팅되어야 한다.

구문 패턴 설명: 'shall be routed to ~' (~로 라우팅/전달되어야 한다)
- 네트워크 엔티티나 서비스 간 트래픽/메시지 전달 경로를 기술 규격에서 명시할 때 빈번하게 쓰이는 구조입니다.
- SHALL/MUST는 명세서상 반드시 구현해야 하는 필수 동작(Mandatory)을 뜻합니다.

**Q.** If the received message contains an invalid IE, the request shall be rejected with cause 'Invalid Mandatory Information'.

**A.** 뜻: 수신된 메시지에 유효하지 않은 IE(Information Element)가 포함되어 있는 경우, 요청은 'Invalid Mandatory Information' 원인 코드와 함께 거부되어야 한다.

구문 패턴 설명: 'shall be rejected with cause ~' (~라는 원인 코드와 함께 거부되어야 한다)
- 통신 프로토콜 규격에서 요청 처리 실패 시 특정 사유 코드(Cause Code)를 반환해야 함을 정의할 때 유용하게 쓰입니다.

**Q.** The newly generated access token shall be appended to the HTTP Authorization header as a bearer token.

**A.** 뜻: 새로 생성된 액세스 토큰은 HTTP Authorization 헤더에 베어러 토큰으로 덧붙여져야 한다.

구문 패턴 설명: 'shall be appended to ~' (~에 추가되어야/덧붙여져야 한다)
- 기존 데이터 구조, 헤더, 문자열, 리스트 끝에 새로운 요소를 결합하는 동작을 규정할 때 사용합니다.

**Q.** To prevent resource exhaustion, the Pod memory limit SHOULD be configured to avoid OOM killing of critical processes.

**A.** 뜻: 자원 고갈을 방지하기 위해, Pod 메모리 제한은 주요 프로세스의 OOM 종료를 피하도록 설정하는 것이 권장된다.

구문 패턴 설명: 'SHOULD be configured to ~' (~하도록 설정하는 것이 권장된다)
- 표준 문서에서 SHOULD는 권장 사항(Recommended)을 나타냅니다. 정당한 사유가 있다면 다른 방식을 택할 수도 있지만 가급적 준수할 것을 권장할 때 쓰입니다.

## GitHub 소통 문구

**Q.** 코드 동작은 문제없지만, 가독성이나 성능을 위해 '이런 방식으로 다르게 작성해보는 건 어떨까요?'라고 조심스럽게 아이디어를 제안하고 싶을 때

**A.** 영어 표현: Just a thought, but we could [refactor this to use a map instead].

유사 표현:
- Alternatively, we might want to...
- How about considering...?

사용 상황: 강요하지 않으면서도 더 나은 대안을 가볍게 제안하거나 리뷰어로서 의견을 공유할 때 쓰입니다.

**Q.** 리뷰어의 지적이나 제안을 듣고 '아, 제가 착각했네요! 말씀해주신 대로 수정했습니다'라고 답변하고 싶을 때

**A.** 영어 표현: Ah, my mistake! I've updated it as suggested.

유사 표현:
- Good catch! Fixed in the latest commit.
- My bad, I misunderstood that part. It should be resolved now.

사용 상황: 본인의 오해나 실수를 인정하고, 제안사항을 반영해 수정을 완료했음을 알릴 때 사용합니다.

## 생활영어

**Q.** 오늘따라 너무 피곤하거나 집중이 안 되어서 '나 오늘 영 멍하네 / 정신이 딴 데 가 있네'라고 말하고 싶을 때

**A.** 영어 표현: I'm feeling a bit spaced out today.

뉘앙스 설명:
'spaced out'은 피로, 딴생각, 수면 부족 등으로 정신이 몽롱하거나 멍한 상태를 의미합니다. 일상 대화에서 집중하기 힘든 상태나 가벼운 실수를 했을 때 유연하게 변명하거나 상태를 전달할 때 자주 쓰입니다.
