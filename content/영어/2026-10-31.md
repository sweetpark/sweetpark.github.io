# 2026-10-31 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The access token SHALL be passed as a parameter to the API gateway during the authentication handshake.

**A.** 액세스 토큰은 인증 핸드셰이크 동안 API 게이트웨이에 파라미터로 전달되어야 한다.

- 구문 패턴: SHALL be passed as a parameter to ~ (~에 파라미터로 전달되어야 한다)
- 규격 구문: SHALL은 강제적 필수 요구사항(Mandatory)을 의미하며, 시스템 구현 시 반드시 준수해야 함을 나타냅니다.

**Q.** The optional payload field MAY be omitted if and only if the status code indicates a no-content response.

**A.** 선택적 페이로드 필드는 상태 코드가 내용 없음(no-content) 응답을 나타내는 경우에 한해서만 생략될 수 있다.

- 구문 패턴: MAY be omitted if and only if ~ (~인 경우에 한해 생략 가능하다)
- 규격 구문: MAY는 선택적 사양(Optional)을 의미하고, 'if and only if'는 필요충분조건(오직 해당 조건일 때만)을 지정할 때 쓰입니다.

**Q.** The client MUST NOT retransmit the request until the cooldown timer expires.

**A.** 클라이언트는 쿨다운 타이머가 만료될 때까지 요청을 재전송해서는 안 된다.

- 구문 패턴: MUST NOT [verb] until ~ (~할 때까지 -해서는 안 된다)
- 규격 구문: MUST NOT은 절대 금지(Prohibited) 사항을 나타냅니다. 'until' 조건과 함께 사용하여 특정 시점 이전까지의 동작 제한을 규정합니다.

**Q.** Configuration updates SHALL be propagated to all downstream replicas within the cluster.

**A.** 설정 변경 사항은 클러스터 내의 모든 하위(downstream) 복제본으로 전파되어야 한다.

- 구문 패턴: SHALL be propagated to ~ (~로 전파되어야 한다)
- 규격 구문: 시스템의 상태 변경이나 이벤트가 다른 컴포넌트로 전달되어야 하는 의무 동작을 정의할 때 사용됩니다.

## GitHub 소통 문구

**Q.** 리뷰 중 테스트 케이스가 부족해 보여서, '테스트 케이스를 몇 개 더 추가해 주시면 좋을 것 같습니다'라고 정중하게 요청하고 싶을 때

**A.** It would be great if we could add a few more test cases for this scenario.

- 유사 표현:
  1. Would it be possible to include some unit tests for edge cases?
  2. Adding a test for this logic would help prevent regressions.
- 사용 상황: 상대방의 PR에 에지 케이스나 기본 테스트가 부족할 때, 직설적인 지적 대신 권유형으로 부드럽게 테스트 작성을 부탁할 때 쓰입니다.

**Q.** 상대방이 PR 리뷰 피드백을 빠르게 코드에 반영해주었을 때, '빠른 수정/반영 감사합니다!'라고 감사 인사를 건네고 싶을 때

**A.** Thanks for the quick turnaround!

- 유사 표현:
  1. Thanks for making the updates so quickly!
  2. Appreciate the swift fix!
- 사용 상황: 'turnaround'는 작업 처리 속도 및 시간을 뜻합니다. 리뷰 피드백이 신속하게 반영되어 커밋이 올라왔을 때 작성하는 대표적인 감사 표현입니다.
