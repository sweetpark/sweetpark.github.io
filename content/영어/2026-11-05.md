# 2026-11-05 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The configuration parameters SHALL be consistent with the definition provided in the API specification.

**A.** 뜻: 구성 파라미터는 API 명세서에 제공된 정의와 일치해야 한다.

구문 패턴: `SHALL be consistent with ~` (~와 일치해야 한다 / 모순이 없어야 한다)
- 스펙 문서에서 두 객체나 설정 간의 상호 호환성 및 일치성을 강제할 때 빈번하게 사용됩니다.
- `MUST match ~`와 유사하지만 `consistent with`는 단순 일치를 넘어 명세 간의 충돌이 없어야 함을 강조합니다.

**Q.** The API server SHALL reject any request containing an unrecognized query parameter.

**A.** 뜻: API 서버는 인식할 수 없는 쿼리 파라미터를 포함한 모든 요청을 거부해야 한다.

구문 패턴: `SHALL reject any ~ containing ...` (...을 포함하는 모든 ~를 거부해야 한다)
- 입력 유효성 검사(Validation) 관련 명세에서 비정상 또는 미지원 파라미터 처리 동작을 명시할 때 자주 쓰입니다.

**Q.** Resource limits MAY be expressed in terms of fractional CPU units or bytes of memory.

**A.** 뜻: 리소스 제한은 CPU 분수 단위 또는 메모리 바이트 단위로 표현될 수 있다.

구문 패턴: `MAY be expressed in terms of ~` (~의 단위로/수치로 표현될 수 있다)
- 스펙에서 단위나 수치 표기 방식을 허용(MAY)할 때 쓰는 표현입니다.
- `in terms of ~`: ~의 측면에서 / ~의 단위로
- `MAY`: 선택적 기능(Optional)을 의미합니다.

**Q.** If the pod fails to start within the specified timeout, it SHALL be marked as degraded.

**A.** 뜻: 지정된 타임아웃 내에 파드가 시작되지 않으면, 결함(degraded) 상태로 표시되어야 한다.

구문 패턴: `SHALL be marked as ~` (~ 상태로 표시/분류되어야 한다)
- 시스템 조건 불충족 시 객체의 상태(Status) 전환을 강제할 때 쓰입니다.
- `degraded`는 K8s/클라우드 스펙에서 정상 동작을 못하는 비정상 상태를 지칭하는 대표적 용어입니다.

## GitHub 소통 문구

**Q.** 이럴 때 뭐라고 말하지?
"사소한 부분이긴 한데, 이번 PR 작업하시는 김에 같이 수정해 주실 수 있나요?"

**A.** 영어 표현: "It's a minor thing, but mind fixing this while you're at it?"

유사 표현:
- "Not a big deal, but could you address this in this PR if possible?"
- "Since we're already touching this file, could we quickly clean this up?"

사용 상황:
코드 리뷰 시 승인을 막을 정도의 블로커(Blocker)는 아니지만, 동일 파일이나 관련 코드를 다루는 김에 함께 정리해주길 부드럽게 요청할 때 사용합니다.

**Q.** 이럴 때 뭐라고 말하지?
"PR 설명이 정말 명확해서 이해하며 리뷰하기 쉬웠어요! 감사해요."

**A.** 영어 표현: "The PR description is super clear and easy to follow. Thanks!"

유사 표현:
- "Great context in the PR description! It made reviewing so much easier."
- "Really appreciate the detailed PR description, made this very smooth to review."

사용 상황:
PR의 배경 설명, 변경 이유, 테스트 방법 등이 깔끔하게 작성되어 리뷰어의 수고를 덜어준 작성자에게 긍정적인 피드백을 남길 때 사용합니다.

## 생활영어

**Q.** 이럴 때 뭐라고 말하지?
"죄송한데 목소리가 약간 끊겨서(깨져서) 들려요."

**A.** 영어 표현: "Sorry, you're breaking up a bit."

뉘앙스 설명:
화상 회의(Zoom, Slack huddle 등)나 통화 중 상대방의 네트워크 상태 불안정으로 음성이 뚝뚝 끊기거나 찌그러져 들릴 때 쓰는 대표적인 관용 표현입니다.
비슷한 표현으로 "Your audio is lagging"이나 "You're coming through faint"가 있습니다.

## 단어

**Q.** Quorum

**A.** 뜻: (분산 시스템에서의) 의결 정족수, 합의를 위한 최소 노드 수

예문:
"The cluster lost quorum after three nodes failed simultaneously."
(3개의 노드가 동시에 장애를 일으킨 후 클러스터의 정족수가 깨졌습니다.)

설명:
etcd, ZooKeeper, Raft 알고리즘 등 분산 백엔드 시스템에서 데이터 일관성을 유지하고 Split-brain 현상을 방지하기 위해 필요한 최소 과반수 노드 응답 수를 의미합니다.
