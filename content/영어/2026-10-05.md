# 2026-10-05 영어 학습

## 3GPP/K8s 기술문서 표현

**Q.** The UE shall maintain the connection for the duration of the active session.

**A.** 뜻: ~가 지속되는 동안
구문 설명: 특정 세션, 타이머, 상태가 유지되는 구체적인 전체 기간 동안 규정이 계속 적용됨을 나타낼 때 사용하는 전형적인 스펙 구문입니다.
관련 비교: 일반적인 'during'보다 표준 문서에서는 기간의 연속성과 범위(Start-to-End)를 엄격히 한정하는 'for the duration of'를 선호합니다.

**Q.** Upon receiving the HTTP request, the pod shall initiate the termination process in response to the shutdown signal.

**A.** 뜻: ~에 대한 응답/반응으로
구문 설명: 시스템이 어떤 이벤트나 원인 신호(Signal/Trigger)를 수신했을 때 그 직후 수반되는 특정 동작을 기술할 때 사용하는 구문입니다.

**Q.** If the field is omitted, the replica count is assumed to be 1.

**A.** 뜻: ~인 것으로 간주된다 / 전제된다
구문 설명: 값이나 옵션이 생략(omitted)되었을 때 프로토콜이나 컨트롤러가 기본 전제 조건(Default assumption)으로 취하는 상태를 정의할 때 사용합니다.

**Q.** The re-authentication procedure shall be triggered by the expiration of the session timer.

**A.** 뜻: ~에 의해 트리거/개시되어야 한다
구문 설명: 특정 절차(Procedure)의 시작 조건이나 계기를 명시할 때 'shall + be triggered by' 형태를 사용합니다. 'shall'이 포함되어 규격상 필수적인 트리거 동작임을 나타냅니다.

## GitHub 소통 문구

**Q.** 이럴 때 뭐라고 말하지?
테스트 도중 이전에 못 보던 버그를 발견했는데, 혹시 기존에 인지되어 있던 문제인지 팀원들에게 가볍게 확인하고 싶을 때

**A.** 영어 표현: Is this a known issue?
유사 표현: Has this been reported before? / Is this a known bug?
사용 상황: 이슈를 새로 생성하거나 본격적인 조사에 들어가기 전, 기존 팀원들이 이미 알고 있는 이슈인지 피드백을 구할 때 자주 사용하는 유용한 질문입니다.

**Q.** 이럴 때 뭐라고 말하지?
PR 피드백 수정을 완료한 후, 리뷰어에게 '시간 되실 때 한번 확인해 주세요'라고 줄여서 가볍게 남기고 싶을 때

**A.** 영어 표현: PTAL (Please Take A Look)
유사 표현: PTAL when you have a moment. / Ready for another look!
사용 상황: GitHub PR 댓글이나 개발자 슬랙 채널에서 리뷰 재요청 시 간결하게 주고받는 대표적인 인쇄용 줄임말입니다.

## 생활영어

**Q.** 이럴 때 뭐라고 말하지?
동료나 협력업체 사람에게 '조만간 진행 상황 공유할 겸 가볍게 한 번 미팅/연락하시죠'라고 제안할 때

**A.** 영어 표현: Let's touch base next week.
뉘앙스 설명: 'touch base'는 거창한 정식 회의를 잡기보다는, 진행 상황을 서로 업데이트하거나 짧게 안부를 확인(check-in)할 때 사용하는 매우 자주 쓰이는 비즈니스 캐주얼 표현입니다.
